## 🔍 OGÓLNA OCENA
Dokument prezentuje **dojrzałą, minimalistyczną i spójną koncepcyjnie wizję** zdecentralizowanego systemu agentowego. Filozofia emergencji, reputacji i pamięci jest trafnie osadzona w aktualnych trendach (autonomiczne agenty, Web of Trust, event-driven architecture). System jest jednak na etapie **architektonicznego szkicu**, który wymaga weryfikacji pod kątem bezpieczeństwa, skalowalności i produkcyjnej wykonalności. Poniżej znajduje się szczegółowa analiza ryzyk oraz konkretne, gotowe do implementacji rozwiązania.

## ⚖️ KRYTYCZNA ANALIZA

| Obszar | Mocne strony | Ryzyka / Luki |
|--------|--------------|---------------|
| **Filozofia** | Minimalizm, emergencja, reputacja jako klucz dostępu | Brak mechanizmów obrony przed emergentną degeneracją (np. echo-chamber trust, colluzja) |

## 🛠 NAJLEPSZE ROZWIĄZANIA (PRIORYTETYZOWANE)

### 🔐 1. Tożsamość Kryptograficzna od Dnia 1
**Problem:** `KnownNodes` w pamięci + brak signing = łatwy spoofing invite'ów.  
**Rozwiązanie:**
- Każdy node generuje przy pierwszym uruchomieniu `ed25519` keypair.
- `Invite` = `SignedPayload{TargetPubKey, InviterPubKey, Timestamp, ChainHash}`
- Weryfikacja: `ed25519.Verify(inviterPub, payload, signature)` + walidacja łańcucha zaproszeń.
- Biblioteka: `golang.org/x/crypto/ed25519`

### 📊 2. Trust Engine 2.0 (Bayesian + Decay + Graph Weight)
**Problem:** Liniowy scoring nie skaluje się, nie broni przed colluzją/Sybil.  
**Rozwiązanie:**
```go
type TrustScore struct {
    WeightedSuccess float64
    Volume          int
    LastUpdated     time.Time
    InviterWeight   float64 // waga zapraszającego node'u
}
func UpdateTrust(old, success bool, inviterWeight float64) float64 {
    decay := math.Exp(-time.Since(old.LastUpdated).Hours() / 720.0) // ~30 dni half-life
    delta := map[bool]float64{true: 0.15, false: -0.30}[success]
    return old.WeightedSuccess*decay + delta*inviterWeight
}
```
- Dodaj `trust_threshold` do uprawnień (np. `<0.4` → tylko read, `>0.7` → może zapraszać).
- Implementuj **EigenTrust-lite**: waga trustu przepływa przez graf zaproszeń.

### 🗃️ 3. Memory System → Event-Sourcing + CRDT + SQLite
**Problem:** Płaska struktura, brak replikacji i konfliktów.  
**Rozwiązanie:**
- Local storage: `SQLite` lub `BoltDB` z indeksami (`task_hash`, `timestamp`, `trust_level`)
- Replikacja: `CRDT` (np. `Yjs`/`Automerge` w Go lub własny Merkle DAG)
- Pattern: Append-only event log z checkpointami co N wykonania
- Dodaj `semantic_index` (opcjonalnie: wektory z `go-vector` lub `llama.cpp` embeddingi)

### 📦 4. Event Bus → Typowany, z Backpressure i Observability
**Problem:** `chan string` → brak kontekstu, retry, metryk.  
**Rozwiązanie:**
```go
type Event struct {
    ID      string
    Type    string // "planner.done", "builder.ok", "validator.pass"
    Payload any    // typed struct
    TraceID string // OpenTelemetry
    Retry   int
}
var EventBus = make(chan Event, 1000) // buffered + worker pool
```
- Dodaj `slog` structured logging + `OpenTelemetry` tracing
- Backpressure: `semaphore` lub `worker pool` z limitami

### 🛡️ 5. Builder/Validator → Sandboxing + Determinizm
**Problem:** Dynamiczne generowanie kodu bez izolacji = RCE.  
**Rozwiązanie:**
- Kompiluj/uruchamiaj w `WASM` (`wazero` runtime w Go)
- Limity: CPU timeout (5s), RAM (128MB), FS (readonly), Network (none)
- Walidacja: AST/static analysis przed execution + hash result verification
- Fallback: jeśli builder generuje niedozwolone importy → `fail` + `-0.3 trust`

### 🌐 6. P2P Transport → libp2p od Phase 1.5
**Problem:** HTTP MVP = fake decentralization.  
**Rozwiązanie:**
- MVP: HTTP + JWT/invite signing (ok dla testów)
- Phase 1.5: `go-libp2p` + `QUIC` + `DHT` + `PubSub`
- NAT traversal: `libp2p` obsługuje automatycznie (relay, hole punching)
- Gossip: `pubsub` z topic-based routing (`/tasks`, `/trust`, `/memory`)

## 1. PRZEGLĄD I FILOZOFIA

### 1.1 Cel StemCell

StemCell to **abstrakcyjna klasa bazowa** dla wszystkich modułów w systemie P2P 60-24 OneClick Evo. Inspiracją jest biologia komórek macierzystych:

- **Komórka macierzysta** → może się różnicować w dowolny typ komórki
- **StemCell** → może się specjalizować w dowolny moduł systemu

### 1.2 Analogie Biologiczne

| Biologia | Technologia | Opis |
|----------|-------------|------|
| Błona komórkowa | Interface | Granica między modułem a światem zewnętrznym |
| Jądro komórkowe | Core Logic | Logika biznesowa modułu |
| Mitochondria | ResourceManager | Zarządzanie energią (CPU/RAM/bandwidth) |
| Receptory | EventReceptor | Odbieranie sygnałów z sieci |
| Podział komórki | `spawn()` | Klonowanie modułu |
| Różnicowanie | `specialize()` | Adaptacja do konkretnej roli |
| Apoptoza | `shutdown()` | Bezpieczne zakończenie działania |
| Homeostaza | `healthcheck()` | Monitorowanie stanu zdrowia |

### 1.3 Zasady Projektowe

1. **Immutability** — konfiguracja jest niezmienna po inicjalizacji
2. **Isolation** — każdy moduł działa w izolowanym kontekście
3. **Observability** — pełny logging i metryki
4. **Fault Tolerance** — graceful degradation przy błędach
5. **Resource Awareness** — świadomość zużycia zasobów

```typescript
// types/core.ts

/** Unikalny identyfikator modułu */
export type ModuleId = string;

/** Rola modułu w systemie */
export type ModuleRole = 
  | 'education/tutor'
  | 'education/student'
  | 'health/monitor'
  | 'health/advisor'
  | 'agriculture/sensor'
  | 'agriculture/planner'
  | 'finance/wallet'
  | 'finance/exchange'
  | 'transport/driver'
  | 'transport/passenger'
  | 'culture/creator'
  | 'culture/consumer'
  | 'generic/worker';

/** Stan modułu */
export enum ModuleState {
  CREATED = 'created',
  INITIALIZING = 'initializing',
  INITIALIZED = 'initialized',
  SPECIALIZED = 'specialized',
  ACTIVE = 'active',
  DEGRADED = 'degraded',
  STOPPING = 'stopping',
  STOPPED = 'stopped',
  FAILED = 'failed'
}

/** Konfiguracja modułu */
export interface ModuleConfig {
  /** Unikalny ID modułu (auto-generowany jeśli brak) */
  moduleId?: ModuleId;
  
  /** Rola początkowa */
  role?: ModuleRole;
  
  /** Limit CPU (w millicores, 1000 = 1 core) */
  cpuLimit?: number;
  
  /** Limit pamięci RAM (w MB) */
  memoryLimit?: number;
  
  /** Limit bandwidth (w MB/s) */
  bandwidthLimit?: number;
  
  /** Timeout na wykonanie zadania (ms) */
  taskTimeout?: number;
  
  /** Poziom logowania */
  logLevel?: 'debug' | 'info' | 'warn' | 'error';
  
  /** Konfiguracja specyficzna dla roli */
  roleConfig?: Record<string, any>;
  
  /** Endpointy sieciowe */
  network?: {
    p2pEnabled: boolean;
    gossipTopics: string[];
    maxPeers: number;
  };
  
  /** Persistencja */
  storage?: {
    enabled: boolean;
    path?: string;
    maxSizeMB?: number;
  };
}

/** Status zdrowia modułu */
export interface HealthStatus {
  /** Czy moduł jest zdrowy */
  ok: boolean;
  
  /** Poziom degradacji (0-1, gdzie 0 = full health) */
  degradation: number;
  
  /** Zużycie CPU (%) */
  cpuUsage: number;
  
  /** Zużycie pamięci (MB) */
  memoryUsage: number;
  
  /** Liczba aktywnych zadań */
  activeTasks: number;
  
  /** Czas ostatniej aktywności */
  lastActivity: Date;
  
  /** Błędy (jeśli wystąpiły) */
  errors?: string[];
  
  /** Metryki specyficzne dla modułu */
  customMetrics?: Record<string, any>;
}

/** Zdarzenie sieciowe */
export interface NetworkEvent {
  /** Typ zdarzenia */
  type: string;
  
  /** Źródło zdarzenia (NodeID) */
  source: string;
  
  /** Cel zdarzenia */
  target?: string;
  
  /** Dane zdarzenia */
  payload: any;
  
  /** Timestamp */
  timestamp: Date;
  
  /** Priorytet (0-10) */
  priority: number;
  
  /** TTL (time-to-live w ms) */
  ttl: number;
  
  /** Signature (dla weryfikacji) */
  signature?: string;
}

/** Odpowiedź na zdarzenie */
export interface Response {
  /** Czy operacja się powiodła */
  success: boolean;
  
  /** Dane odpowiedzi */
  data?: any;
  
  /** Kod błędu (jeśli wystąpił) */
  errorCode?: string;
  
  /** Wiadomość błędu */
  errorMessage?: string;
  
  /** Czas wykonania (ms) */
  executionTime: number;
  
  /** Zużycie zasobów */
  resourceUsage?: {
    cpu: number;
    memory: number;
    bandwidth: number;
  };
}

/**
 * Interfejs wszystkich modułów w systemie P2P 60-24

   * ```typescript

  spawn(): Promise<IModule>;

  communicate(event: NetworkEvent): Promise<Response>;

   * Sprawdzenie stanu zdrowia modułu

   * Zwraca metryki wydajności i ewentualne błędy.
   * 
   * @example
   * ```typescript
   * const health = module.healthcheck();
   * if (!health.ok) {
   *   logger.warn('Module degraded:', health);
   * }
   * ```
   */
  healthcheck(): HealthStatus;

   * Bezpieczne zakończenie działania modułu

   * @remarks
   * Metoda powinna:
   * 1. Zakończyć aktywne zadania (gracefully)
   * 2. Zapisać stan (jeśli wymagane)
   * 3. Zwolnić zasoby
   * 4. Odsubskrybować zdarzenia
   * 
   * @example
   * ```typescript
   * await module.shutdown();
   * ```

  shutdown(): Promise<void>;

import { IModule } from '../interfaces/IModule';
import { 
  ModuleConfig, 
  ModuleState, 
  HealthStatus, 
  NetworkEvent, 
  Response,
  ModuleRole,
  ModuleId
} from '../types/core';
import { ResourceManager } from './ResourceManager';
import { EventBus } from './EventBus';
import { Logger } from '../utils/Logger';
import { v4 as uuidv4 } from 'uuid';
import EventEmitter from 'events';

/**
 * Abstrakcyjna klasa bazowa dla wszystkich modułów
 * 
 * @remarks
 * Implementuje wzorzec Template Method.
 * Konkretne moduły dziedziczą po tej klasie i nadpisują
 * metody abstrakcyjne aby dostarczyć specyficzną logikę.
 * 
 * @example
 * ```typescript
 * class MyModule extends StemCell {
 *   async handleTask(task: any): Promise<any> {
 *     // Implementacja specyficzna dla modułu
 *   }
 * }
 * 
 * const module = new MyModule();
 * await module.init({ cpuLimit: 500, memoryLimit: 256 });
 * ```
 */
export abstract class StemCell implements IModule {
  /** Unikalny identyfikator modułu */
  public readonly moduleId: ModuleId;
  
  /** Aktualny stan modułu */
  public state: ModuleState = ModuleState.CREATED;
  
  /** Konfiguracja modułu (immutable po init) */
  protected config!: ModuleConfig;
  
  /** Menadżer zasobów */
  protected resourceManager!: ResourceManager;
  
  /** System eventów */
  protected eventBus!: EventBus;
  
  /** Logger */
  protected logger!: Logger;
  
  /** Event emitter dla wewnętrznych zdarzeń */
  protected events: EventEmitter;
  
  /** Czas utworzenia */
  protected readonly createdAt: Date;
  
  /** Czas ostatniej aktywności */
  protected lastActivityAt: Date;
  
  /** Licznik aktywnych zadań */
  protected activeTaskCount: number = 0;
  
  /** Subskrypcje eventów */
  private eventSubscriptions: Array<() => void> = [];

  /**
   * Tworzy nową instancję StemCell
   * 
   * @param moduleId - Opcjonalny ID modułu (auto-generowany jeśli brak)
   */
  constructor(moduleId?: ModuleId) {
    this.moduleId = moduleId || uuidv4();
    this.createdAt = new Date();
    this.lastActivityAt = new Date();
    this.events = new EventEmitter();
    this.events.setMaxListeners(100);
  }

  /**
   * Inicjalizacja modułu
   * 
   * @param config - Konfiguracja
   */
  public async init(config: ModuleConfig): Promise<void> {
    this.logger = new Logger(this.moduleId, config.logLevel || 'info');
    this.logger.info(`Initializing module ${this.moduleId}`);
    
    this.state = ModuleState.INITIALIZING;
    
    try {
      // Walidacja konfiguracji
      this.config = this.validateConfig(config);
      this.logger.debug('Config validated', this.config);
      
      // Inicjalizacja resource manager
      this.resourceManager = new ResourceManager(
        this.moduleId,
        this.config
      );
      await this.resourceManager.init();
      this.logger.debug('ResourceManager initialized');
      
      // Inicjalizacja event bus
      this.eventBus = new EventBus(this.moduleId);
      await this.eventBus.init();
      this.logger.debug('EventBus initialized');
      
      // Subskrypcja do zdarzeń systemowych
      await this.subscribeToSystemEvents();
      
      // Alokacja zasobów
      this.allocateResources();
      this.logger.debug('Resources allocated');
      
      // Hook po inicjalizacji (do nadpisania)
      await this.onInit();
      
      this.state = ModuleState.INITIALIZED;
      this.lastActivityAt = new Date();
      
      this.logger.info(`Module ${this.moduleId} initialized successfully`);
      
    } catch (error) {
      this.logger.error('Initialization failed', error);
      this.state = ModuleState.FAILED;
      throw error;
    }
  }

  /**
   * Walidacja konfiguracji
   */
  protected validateConfig(config: ModuleConfig): ModuleConfig {
    const validated: ModuleConfig = {
      ...config,
      moduleId: config.moduleId || this.moduleId,
      cpuLimit: config.cpuLimit || 1000, // 1 core default
      memoryLimit: config.memoryLimit || 512, // 512MB default
      bandwidthLimit: config.bandwidthLimit || 10, // 10MB/s default
      taskTimeout: config.taskTimeout || 30000, // 30s default
      logLevel: config.logLevel || 'info',
    };

    // Walidacja zakresów
    if (validated.cpuLimit < 100 || validated.cpuLimit > 8000) {
      throw new Error('cpuLimit must be between 100 and 8000 millicores');
    }
    if (validated.memoryLimit < 64 || validated.memoryLimit > 4096) {
      throw new Error('memoryLimit must be between 64 and 4096 MB');
    }
    if (validated.taskTimeout < 1000 || validated.taskTimeout > 300000) {
      throw new Error('taskTimeout must be between 1000 and 300000 ms');
    }

    return validated;
  }

  /**
   * Alokacja zasobów
   */
  protected allocateResources(): void {
    this.resourceManager.allocate({
      cpu: this.config.cpuLimit!,
      memory: this.config.memoryLimit!,
      bandwidth: this.config.bandwidthLimit!
    });
  }

  /**
   * Subskrypcja do zdarzeń systemowych
   */
  private async subscribeToSystemEvents(): Promise<void> {
    // Subskrypcja do zdarzeń healthcheck
    const healthSub = this.eventBus.subscribe('system/healthcheck', async (event) => {
      const health = this.healthcheck();
      return { success: true,  health };
    });
    this.eventSubscriptions.push(healthSub);

    // Subskrypcja do zdarzeń shutdown
    const shutdownSub = this.eventBus.subscribe('system/shutdown', async () => {
      await this.shutdown();
      return { success: true };
    });
    this.eventSubscriptions.push(shutdownSub);

    this.logger.debug('Subscribed to system events');
  }

  /**
   * Hook po inicjalizacji (do nadpisania przez podklasy)
   */
  protected async onInit(): Promise<void> {
    // Domyślnie puste - do nadpisania
  }

    const child = await this.createChildInstance();

   */
  protected abstract createChildInstance(): Promise<IModule>;

  /**
   * Obsługa zdarzenia sieciowego
   */
  public async communicate(event: NetworkEvent): Promise<Response> {
    const startTime = Date.now();
    this.lastActivityAt = new Date();
    this.activeTaskCount++;
    
    this.logger.debug(`Handling event: ${event.type}`, event);
    
    try {
      // Weryfikacja TTL
      if (Date.now() - event.timestamp.getTime() > event.ttl) {
        this.logger.warn('Event TTL expired');
        return {
          success: false,
          errorCode: 'TTL_EXPIRED',
          errorMessage: 'Event has expired',
          executionTime: Date.now() - startTime
        };
      }
      
      // Weryfikacja podpisu (jeśli wymagany)
      if (event.signature && !await this.verifySignature(event)) {
        this.logger.warn('Invalid signature');
        return {
          success: false,
          errorCode: 'INVALID_SIGNATURE',
          errorMessage: 'Event signature verification failed',
          executionTime: Date.now() - startTime
        };
      }
      
      // Sprawdzenie zasobów
      if (!this.resourceManager.hasAvailableResources()) {
        this.logger.warn('Insufficient resources');
        return {
          success: false,
          errorCode: 'INSUFFICIENT_RESOURCES',
          errorMessage: 'Module has insufficient resources',
          executionTime: Date.now() - startTime
        };
      }
      
      // Alokacja zasobów dla tego zadania
      const resourceAllocation = this.resourceManager.allocateForTask();
      
      try {
        // Obsługa zdarzenia (implementacja w podklasie)
        const result = await this.handleEvent(event);
        
        // Zwolnienie zasobów
        this.resourceManager.releaseForTask(resourceAllocation);
        
        return {
          success: true,
           result,
          executionTime: Date.now() - startTime,
          resourceUsage: {
            cpu: resourceAllocation.cpu,
            memory: resourceAllocation.memory,
            bandwidth: resourceAllocation.bandwidth
          }
        };
        
      } catch (error) {
        this.resourceManager.releaseForTask(resourceAllocation);
        throw error;
      }
      
    } catch (error) {
      this.logger.error('Event handling failed', error);
      
      return {
        success: false,
        errorCode: error instanceof Error ? error.name : 'UNKNOWN_ERROR',
        errorMessage: error instanceof Error ? error.message : 'Unknown error',
        executionTime: Date.now() - startTime
      };
      
    } finally {
      this.activeTaskCount--;
    }
  }

  /**
   * Weryfikacja podpisu zdarzenia (do implementacji)
   */
  protected async verifySignature(event: NetworkEvent): Promise<boolean> {
    // Domyślnie akceptujemy wszystkie (do zaimplementowania krypto)
    return true;
  }

  /**
   * Obsługa zdarzenia (do nadpisania przez podklasy)
   */
  protected abstract handleEvent(event: NetworkEvent): Promise<any>;

  /**
   * Sprawdzenie stanu zdrowia
   */
  public healthcheck(): HealthStatus {
    const resourceStats = this.resourceManager.getStats();
    const timeSinceLastActivity = Date.now() - this.lastActivityAt.getTime();
    
    // Obliczanie poziomu degradacji
    let degradation = 0;
    if (resourceStats.cpuUsage > 90) degradation += 0.3;
    if (resourceStats.memoryUsage > 90) degradation += 0.3;
    if (timeSinceLastActivity > 60000) degradation += 0.2; // 1 min bez aktywności
    if (this.activeTaskCount > 10) degradation += 0.2;
    
    const isHealthy = degradation < 0.5 && this.state !== ModuleState.FAILED;
    
    return {
      ok: isHealthy,
      degradation: Math.min(degradation, 1),
      cpuUsage: resourceStats.cpuUsage,
      memoryUsage: resourceStats.memoryUsage,
      activeTasks: this.activeTaskCount,
      lastActivity: this.lastActivityAt,
      customMetrics: this.getCustomHealthMetrics()
    };
  }

  /**
   * Dodatkowe metryki zdrowia (do nadpisania)
   */
  protected getCustomHealthMetrics(): Record<string, any> {
    return {};
  }

  /**
   * Bezpieczne zakończenie działania
   */
  public async shutdown(): Promise<void> {
    this.logger.info('Shutting down module');
    
    if (this.state === ModuleState.STOPPED || this.state === ModuleState.STOPPING) {
      this.logger.warn('Module already stopping or stopped');
      return;
    }
    
    this.state = ModuleState.STOPPING;
    
    try {
      // Oczekiwanie na zakończenie aktywnych zadań (max 5s)
      await this.waitForActiveTasks(5000);
      
      // Odsubskrybowanie eventów
      for (const unsubscribe of this.eventSubscriptions) {
        unsubscribe();
      }
      this.eventSubscriptions = [];
      
      // Hook przed zamknięciem
      await this.onShutdown();
      
      // Zamknięcie resource manager
      await this.resourceManager.shutdown();
      
      // Zamknięcie event bus
      await this.eventBus.shutdown();
      
      this.state = ModuleState.STOPPED;
      this.logger.info('Module shut down successfully');
      
    } catch (error) {
      this.logger.error('Shutdown failed', error);
      this.state = ModuleState.FAILED;
      throw error;
    }
  }

  /**
   * Oczekiwanie na zakończenie aktywnych zadań
   */
  private async waitForActiveTasks(timeout: number): Promise<void> {
    const startTime = Date.now();
    
    while (this.activeTaskCount > 0) {
      if (Date.now() - startTime > timeout) {
        this.logger.warn('Timeout waiting for active tasks');
        break;
      }
      await new Promise(resolve => setTimeout(resolve, 100));
    }
  }

  /**
   * Hook przed zamknięciem (do nadpisania)
   */
  protected async onShutdown(): Promise<void> {
    // Domyślnie puste
  }

  /**
   * Zwolnienie zasobów
   */
  protected releaseResources(): void {
    this.resourceManager.releaseAll();
  }
}

// modules/EducationModule.ts

import { StemCell } from '../core/StemCell';
import { IModule } from '../interfaces/IModule';
import { NetworkEvent, Response, ModuleRole, HealthStatus } from '../types/core';

/**
 * Dane kursu
 */
interface Course {
  id: string;
  name: string;
  description: string;
  level: 'beginner' | 'intermediate' | 'advanced';
  topics: string[];
  enrolledStudents: Set<string>;
  createdAt: Date;
}

/**
 * Zadanie edukacyjne
 */
interface LearningTask {
  type: 'learn' | 'teach' | 'assess' | 'discuss';
  subject: string;
  difficulty: number; // 1-10
  content?: any;
  targetStudent?: string;
}

/**
 * Moduł Edukacji
 * 
 * @remarks
 * Implementuje funkcjonalności związane z nauką:
 * - Tworzenie i zarządzanie kursami
 * - Mentoring P2P
 * - Śledzenie postępów
 * - Rekomendacje AI (przez Decision Engine)
 */
export class EducationModule extends StemCell {
  /** Repozytorium kursów */
  private courses: Map<string, Course> = new Map();
  
  /** Zarejestrowani studenci */
  private students: Set<string> = new Set();
  
  /** Aktywne sesje nauki */
  private activeSessions: Map<string, LearningTask> = new Map();
  
  /** Metryki edukacyjne */
  private metrics = {
    totalCourses: 0,
    totalStudents: 0,
    completedTasks: 0,
    averageScore: 0
  };

  /**
   * Tworzenie instancji potomnej
   */
  protected async createChildInstance(): Promise<IModule> {
    return new EducationModule();
  }

  /**
   * Hook po inicjalizacji
   */
  protected async onInit(): Promise<void> {
    this.logger.info('EducationModule initialized');
    
    // Ładowanie istniejących kursów z storage (jeśli włączone)
    if (this.config.storage?.enabled) {
      await this.loadCoursesFromStorage();
    }
  }

  /**
   * Ładowanie logiki specyficznej dla roli
   */
  protected loadRoleSpecificLogic(role: ModuleRole): void {
    switch (role) {
      case 'education/tutor':
        this.logger.info('Loaded tutor logic');
        break;
      case 'education/student':
        this.logger.info('Loaded student logic');
        break;
      default:
        this.logger.warn(`Unknown education role: ${role}`);
    }
  }

  /**
   * Obsługa zdarzeń
   */
  protected async handleEvent(event: NetworkEvent): Promise<any> {
    switch (event.type) {
      case 'education/course/create':
        return this.createCourse(event.payload);
      
      case 'education/course/enroll':
        return this.enrollStudent(event.payload);
      
      case 'education/task/execute':
        return this.executeLearningTask(event.payload);
      
      case 'education/student/register':
        return this.registerStudent(event.payload);
      
      case 'education/metrics/get':
        return this.getMetrics();
      
      default:
        this.logger.warn(`Unknown event type: ${event.type}`);
        throw new Error(`Unsupported event type: ${event.type}`);
    }
  }

  /**
   * Tworzenie kursu
   */
  private async createCourse(payload: any): Promise<Course> {
    const course: Course = {
      id: this.generateId(),
      name: payload.name,
      description: payload.description || '',
      level: payload.level || 'beginner',
      topics: payload.topics || [],
      enrolledStudents: new Set(),
      createdAt: new Date()
    };
    
    this.courses.set(course.id, course);
    this.metrics.totalCourses++;
    
    this.logger.info(`Created course: ${course.name}`);
    
    // Persistencja jeśli włączona
    if (this.config.storage?.enabled) {
      await this.saveCourseToStorage(course);
    }
    
    return course;
  }

  /**
   * Zapis studenta na kurs
   */
  private async enrollStudent(payload: { courseId: string; studentId: string }): Promise<boolean> {
    const course = this.courses.get(payload.courseId);
    if (!course) {
      throw new Error(`Course not found: ${payload.courseId}`);
    }
    
    course.enrolledStudents.add(payload.studentId);
    this.students.add(payload.studentId);
    this.metrics.totalStudents = this.students.size;
    
    this.logger.info(`Student ${payload.studentId} enrolled in ${course.name}`);
    
    return true;
  }

  /**
   * Wykonanie zadania edukacyjnego
   */
  private async executeLearningTask(task: LearningTask): Promise<any> {
    const sessionId = this.generateId();
    this.activeSessions.set(sessionId, task);
    
    this.logger.info(`Executing task: ${task.type} - ${task.subject}`);
    
    try {
      let result: any;
      
      switch (task.type) {
        case 'learn':
          result = await this.learn(task);
          break;
        case 'teach':
          result = await this.teach(task);
          break;
        case 'assess':
          result = await this.assess(task);
          break;
        case 'discuss':
          result = await this.discuss(task);
          break;
      }
      
      this.metrics.completedTasks++;
      
      return {
        sessionId,
        task,
        result,
        completedAt: new Date()
      };
      
    } finally {
      this.activeSessions.delete(sessionId);
    }
  }

  /**
   * Nauka (implementacja uproszczona)
   */
  private async learn(task: LearningTask): Promise<any> {
    // Tutaj integracja z AI/Decision Engine
    return {
      status: 'learning',
      subject: task.subject,
      progress: 0,
      estimatedTime: task.difficulty * 5 // minutes
    };
  }

  /**
   * Nauczanie (implementacja uproszczona)
   */
  private async teach(task: LearningTask): Promise<any> {
    return {
      status: 'teaching',
      subject: task.subject,
      targetStudent: task.targetStudent,
      materials: this.generateTeachingMaterials(task)
    };
  }

  /**
   * Ocena (implementacja uproszczona)
   */
  private async assess(task: LearningTask): Promise<any> {
    return {
      status: 'assessed',
      score: Math.random() * 100, // Placeholder
      feedback: 'Good progress!'
    };
  }

  /**
   * Dyskusja (implementacja uproszczona)
   */
  private async discuss(task: LearningTask): Promise<any> {
    return {
      status: 'discussing',
      topic: task.subject,
      participants: []
    };

### 6.1 EventBus Implementation

```typescript
// core/EventBus.ts

import EventEmitter from 'events';
import { Logger } from '../utils/Logger';

export interface EventPayload {
  type: string;
  data: any;
  timestamp: Date;
  source: string;
}

export type EventHandler = (payload: EventPayload) => Promise<any>;

/**
 * System eventów dla modułów
 */
export class EventBus {
  private emitter: EventEmitter;
  private logger: Logger;
  private subscriptions: Map<string, Set<EventHandler>>;

  constructor(private moduleId: string) {
    this.emitter = new EventEmitter();
    this.emitter.setMaxListeners(100);
    this.subscriptions = new Map();
    this.logger = new Logger(`${moduleId}:eventbus`, 'info');
  }

  public async init(): Promise<void> {
    this.logger.debug('EventBus initialized');
  }

  /**
   * Subskrypcja do eventu
   */
  public subscribe(eventType: string, handler: EventHandler): () => void {
    if (!this.subscriptions.has(eventType)) {
      this.subscriptions.set(eventType, new Set());
    }
    
    this.subscriptions.get(eventType)!.add(handler);
    
    this.logger.debug(`Subscribed to ${eventType}`);
    
    // Return unsubscribe function
    return () => {
      this.subscriptions.get(eventType)?.delete(handler);
      this.logger.debug(`Unsubscribed from ${eventType}`);
    };
  }

  /**
   * Publikacja eventu
   */
  public async publish(eventType: string, data: any): Promise<any[]> {
    const payload: EventPayload = {
      type: eventType,
      data,
      timestamp: new Date(),
      source: this.moduleId
    };

    const handlers = this.subscriptions.get(eventType) || new Set();
    const results = [];

    for (const handler of handlers) {
      try {
        const result = await handler(payload);
        results.push(result);
      } catch (error) {
        this.logger.error(`Handler error for ${eventType}`, error);
      }
    }

    return results;
  }

  public async shutdown(): Promise<void> {
    this.subscriptions.clear();
    this.emitter.removeAllListeners();
    this.logger.debug('EventBus shut down');
  }
}

### 7.1 ResourceManager Implementation

```typescript
// core/ResourceManager.ts

import { ModuleConfig } from '../types/core';
import { Logger } from '../utils/Logger';

interface ResourceAllocation {
  cpu: number;
  memory: number;
  bandwidth: number;
}

interface ResourceStats {
  cpuUsage: number;
  memoryUsage: number;
  bandwidthUsage: number;
  availableCpu: number;
  availableMemory: number;
  availableBandwidth: number;
}

/**
 * Menadżer zasobów modułu
 */
export class ResourceManager {
  private config: ModuleConfig;
  private logger: Logger;
  private allocated: ResourceAllocation;
  private used: ResourceAllocation = { cpu: 0, memory: 0, bandwidth: 0 };

  constructor(
    private moduleId: string,
    config: ModuleConfig
  ) {
    this.config = config;
    this.allocated = {
      cpu: config.cpuLimit || 1000,
      memory: config.memoryLimit || 512,
      bandwidth: config.bandwidthLimit || 10
    };
    this.logger = new Logger(`${moduleId}:resources`, 'debug');
  }

  public async init(): Promise<void> {
    this.logger.debug('ResourceManager initialized');
  }

  /**
   * Alokacja zasobów
   */
  public allocate(resources: ResourceAllocation): void {
    this.allocated = resources;
    this.logger.debug(`Allocated resources: CPU=${resources.cpu}, MEM=${resources.memory}MB`);
  }

  /**
   * Alokacja dla zadania
   */
  public allocateForTask(): ResourceAllocation {
    // Prosta strategia: podział równy
    const allocation: ResourceAllocation = {
      cpu: Math.floor(this.allocated.cpu / 4),
      memory: Math.floor(this.allocated.memory / 4),
      bandwidth: Math.floor(this.allocated.bandwidth / 4)
    };

    this.used.cpu += allocation.cpu;
    this.used.memory += allocation.memory;
    this.used.bandwidth += allocation.bandwidth;

    return allocation;
  }

  /**
   * Zwolnienie zasobów zadania
   */
  public releaseForTask(allocation: ResourceAllocation): void {
    this.used.cpu = Math.max(0, this.used.cpu - allocation.cpu);
    this.used.memory = Math.max(0, this.used.memory - allocation.memory);
    this.used.bandwidth = Math.max(0, this.used.bandwidth - allocation.bandwidth);
  }

  /**
   * Sprawdzenie dostępności zasobów
   */
  public hasAvailableResources(): boolean {
    const usage = this.getStats();
    return usage.cpuUsage < 90 && usage.memoryUsage < 90;
  }

  /**
   * Statystyki zasobów
   */
  public getStats(): ResourceStats {
    return {
      cpuUsage: (this.used.cpu / this.allocated.cpu) * 100,
      memoryUsage: (this.used.memory / this.allocated.memory) * 100,
      bandwidthUsage: (this.used.bandwidth / this.allocated.bandwidth) * 100,
      availableCpu: this.allocated.cpu - this.used.cpu,
      availableMemory: this.allocated.memory - this.used.memory,
      availableBandwidth: this.allocated.bandwidth - this.used.bandwidth
    };
  }

  /**
   * Zwolnienie wszystkich zasobów
   */
  public releaseAll(): void {
    this.used = { cpu: 0, memory: 0, bandwidth: 0 };
    this.logger.debug('All resources released');
  }

  public async shutdown(): Promise<void> {
    this.releaseAll();
    this.logger.debug('ResourceManager shut down');
  }
}

### 1.1 Identity — Tożsamość Kryptograficzna

```typescript
// trust/Identity.ts
import { ed25519 } from '@noble/ed25519';
import { sha3_256 } from '@noble/hashes/sha3';

/**
 * Tożsamość węzła — fundament Web of Trust
 * 
 * @remarks
 * Każdy node generuje parę kluczy przy pierwszym uruchomieniu.
 * NodeID = hash(publicKey) — deterministyczny, unikalny, weryfikowalny.
 */
export class Identity {
  readonly nodeId: string;
  readonly publicKey: Uint8Array;
  readonly privateKey: Uint8Array; // NIGDY nie opuszcza pamięci
  
  trustScore: number = 0.5; // Start z neutralnym zaufaniem
  trustLinks: TrustLink[] = [];
  reputation: ReputationMetrics = {
    tasksCompleted: 0,
    tasksFailed: 0,
    joyContributed: 0,
    lastActive: new Date()
  };
  
  private constructor(
    publicKey: Uint8Array,
    privateKey: Uint8Array
  ) {
    this.publicKey = publicKey;
    this.privateKey = privateKey;
    this.nodeId = this.computeNodeId(publicKey);
  }
  
  /**
   * Generuje nową tożsamość (tylko przy bootstrap)
   */
  static async generate(): Promise<Identity> {
    const privateKey = ed25519.utils.randomPrivateKey();
    const publicKey = await ed25519.getPublicKey(privateKey);
    return new Identity(publicKey, privateKey);
  }
  
  /**
   * Ładuje istniejącą tożsamość z storage
   */
  static async load(
    publicKey: Uint8Array,
    privateKey: Uint8Array
  ): Promise<Identity> {
    return new Identity(publicKey, privateKey);
  }
  
  /**
   * NodeID = first 32 chars of SHA3-256(publicKey)
   */
  private computeNodeId(publicKey: Uint8Array): string {
    const hash = sha3_256(publicKey);
    return Buffer.from(hash).toString('hex').slice(0, 32);
  }
  
  /**
   * Podpisuje dowolną wiadomość
   */
  async sign(message: Uint8Array): Promise<Uint8Array> {
    return await ed25519.sign(message, this.privateKey);
  }
  
  /**
   * Weryfikuje podpis (statyczne — nie potrzebuje privateKey)
   */
  static async verify(
    message: Uint8Array,
    signature: Uint8Array,
    publicKey: Uint8Array
  ): Promise<boolean> {
    return await ed25519.verify(signature, message, publicKey);
  }
  
  /**
   * Serializuje publiczną część tożsamości (do wysłania)
   */
  toPublicJSON(): PublicIdentity {
    return {
      nodeId: this.nodeId,
      publicKey: Buffer.from(this.publicKey).toString('hex'),
      trustScore: this.trustScore,
      trustLinks: this.trustLinks.map(l => ({
        from: l.from,
        weight: l.weight,
        timestamp: l.timestamp.toISOString()
      })),
      reputation: this.reputation
    };
  }
}

export interface PublicIdentity {
  nodeId: string;
  publicKey: string; // hex
  trustScore: number;
  trustLinks: { from: string; weight: number; timestamp: string }[];
  reputation: ReputationMetrics;
}

export interface ReputationMetrics {
  tasksCompleted: number;
  tasksFailed: number;
  joyContributed: number; // happycoin-like metric
  lastActive: Date;
}

export interface TrustLink {
  from: string;           // NodeID who invited me
  weight: number;         // 0.0 - 1.0, waga tego zaproszenia
  timestamp: Date;
  signature: Uint8Array;  // podpis zapraszającego
}
```

### 1.2 SignedInvite — Protokół Zaproszeń

```typescript
// trust/SignedInvite.ts
import { Identity } from './Identity';

/**
 * Zaproszenie do sieci — podpisane kryptograficznie
 * 
 * Flow:
 * 1. Alice (znany node) chce zaprosić Boba
 * 2. Alice tworzy SignedInvite z public key Boba
 * 3. Alice podpisuje invite swoim privateKey
 * 4. Bob wysyła invite do sieci przy join
 * 5. Sieć weryfikuje: podpis Alice + czy Alice ma trust > threshold
 */
export interface InvitePayload {
  inviterNodeId: string;      // kto zaprasza
  inviteePublicKey: string;   // hex public key nowego node
  timestamp: number;          // Unix ms
  nonce: string;              // anti-replay
  capabilities: string[];     // co może robić nowy node
  metadata?: Record<string, any>;
}

export class SignedInvite {
  constructor(
    public payload: InvitePayload,
    public signature: Uint8Array,
    public inviterPublicIdentity: PublicIdentity
  ) {}
  
  /**
   * Tworzy nowe zaproszenie (tylko inviter może to zrobić)
   */
  static async create(
    inviter: Identity,
    inviteePublicKey: Uint8Array,
    options?: Partial<InvitePayload>
  ): Promise<SignedInvite> {
    const payload: InvitePayload = {
      inviterNodeId: inviter.nodeId,
      inviteePublicKey: Buffer.from(inviteePublicKey).toString('hex'),
      timestamp: Date.now(),
      nonce: crypto.randomUUID(),
      capabilities: options?.capabilities || ['compute', 'storage'],
      meta options?.metadata,
      ...options
    };
    
    const message = this.encodePayload(payload);
    const signature = await inviter.sign(message);
    
    return new SignedInvite(
      payload,
      signature,
      inviter.toPublicJSON()
    );
  }
  
  /**
   * Weryfikuje zaproszenie (każdy node może to zrobić)
   */
  static async verify(
    invite: SignedInvite,
    trustThreshold: number = 0.3
  ): Promise<VerificationResult> {
    // 1. Weryfikacja podpisu
    const message = this.encodePayload(invite.payload);
    const publicKey = Buffer.from(invite.inviterPublicIdentity.publicKey, 'hex');
    
    const signatureValid = await Identity.verify(
      message,
      invite.signature,
      publicKey
    );
    
    if (!signatureValid) {
      return { valid: false, reason: 'INVALID_SIGNATURE' };
    }
    
    // 2. Weryfikacja czasu (max 24h na wykorzystanie)
    const age = Date.now() - invite.payload.timestamp;
    if (age > 24 * 60 * 60 * 1000) {
      return { valid: false, reason: 'INVITE_EXPIRED' };
    }
    
    // 3. Weryfikacja trust invitera
    if (invite.inviterPublicIdentity.trustScore < trustThreshold) {
      return { 
        valid: false, 
        reason: 'INVITER_LOW_TRUST',
        inviterTrust: invite.inviterPublicIdentity.trustScore
      };
    }
    
    // 4. Anti-replay: nonce powinien być unikalny (sprawdza Node)
    
    return { valid: true };
  }
  
  /**
   * Encodes payload to bytes for signing
   */
  private static encodePayload(payload: InvitePayload): Uint8Array {
    const json = JSON.stringify(payload, Object.keys(payload).sort());
    return new TextEncoder().encode(json);
  }
}

export interface VerificationResult {
  valid: boolean;

### 1.3 TrustManager — Silnik Zaufania

```typescript
// trust/TrustManager.ts
import { Identity, PublicIdentity, TrustLink } from './Identity';

/**
 * Manager zaufania — implementuje Web of Trust
 * 
 * Model: trust = Σ(link.weight * inviter.trust) / Σ(link.weight)
 * 
 * Zasady:
 * - Trust jest dynamiczny, aktualizowany po każdej interakcji
 * - Decay: trust maleje o 1% dziennie bez aktywności
 * - Threshold gating: node z trust < 0.2 nie może zapraszać
 */
export class TrustManager {
  private knownIdentities: Map<string, PublicIdentity> = new Map();
  private trustCache: Map<string, number> = new Map();
  
  constructor(
    private readonly ownIdentity: Identity,
    private readonly config: TrustConfig
  ) {}
  
  /**
   * Czy node jest zaufany (do komunikacji)
   */
  isTrusted(nodeId: string, minScore: number = 0.2): boolean {
    const score = this.getTrustScore(nodeId);
    return score >= minScore;
  }
  
  /**
   * Oblicza trust score dla node'a
   * 
   * Algorytm: weighted average trust od inviterów
   */
  getTrustScore(nodeId: string): number {
    // Cache hit
    if (this.trustCache.has(nodeId)) {
      return this.trustCache.get(nodeId)!;
    }
    
    const identity = this.knownIdentities.get(nodeId);
    if (!identity) {
      return 0; // Nieznany node = zero trust
    }
    
    if (identity.trustLinks.length === 0) {
      // Genesis node (bez inviterów) — trust z config
      const score = identity.nodeId === this.ownIdentity.nodeId 
        ? 1.0 
        : this.config.defaultTrust;
      this.trustCache.set(nodeId, score);
      return score;
    }
    
    // Weighted average: Σ(weight * inviter_trust) / Σ(weight)
    let weightedSum = 0;
    let weightTotal = 0;
    
    for (const link of identity.trustLinks) {
      const inviter = this.knownIdentities.get(link.from);
      if (inviter) {
        const inviterTrust = this.getTrustScore(link.from); // rekurencja!
        weightedSum += link.weight * inviterTrust;
        weightTotal += link.weight;
      }
    }
    
    const score = weightTotal > 0 
      ? weightedSum / weightTotal 
      : this.config.defaultTrust;
    
    // Apply decay: -1% per day without activity
    const daysInactive = (Date.now() - identity.reputation.lastActive.getTime()) / (1000 * 60 * 60 * 24);
    const decayedScore = score * Math.pow(0.99, daysInactive);
    
    this.trustCache.set(nodeId, decayedScore);
    return decayedScore;
  }
  
  /**
   * Aktualizuje trust po interakcji
   */
  updateTrust(
    nodeId: string, 
    delta: number, 
    reason: TrustUpdateReason
  ): void {
    const identity = this.knownIdentities.get(nodeId);
    if (!identity) return;
    
    // Clamp delta do rozsądnych wartości
    const clampedDelta = Math.max(-0.1, Math.min(0.05, delta));
    
    identity.trustScore = Math.max(0, Math.min(1, identity.trustScore + clampedDelta));
    identity.reputation.lastActive = new Date();
    
    // Log reason dla audytu
    this.logTrustUpdate(nodeId, delta, reason);
    
    // Invalidate cache
    this.trustCache.delete(nodeId);
    this.trustCache.clear(); // Proste: clear all, recompute on demand
  }
  
  /**
   * Dodaje nowe trust link (po weryfikacji invite)
   */
  addTrustLink(nodeId: string, link: TrustLink): boolean {
    // Weryfikacja podpisu linku
    const linkValid = Identity.verify(
      this.encodeLink(link),
      link.signature,
      Buffer.from(link.from, 'hex')
    );
    
    if (!linkValid) return false;
    
    const identity = this.knownIdentities.get(nodeId);
    if (identity) {
      identity.trustLinks.push(link);
      this.trustCache.delete(nodeId);
      return true;
    }
    return false;
  }
  
  /**
   * Znajduje ścieżkę zaufania między node'ami
   */
  findTrustPath(from: string, to: string, maxHops: number = 3): TrustPath[] {
    // BFS do znalezienia najkrótszej ścieżki trust
    // Implementacja uproszczona — w produkcji użyć grafu
    const paths: TrustPath[] = [];
    
    if (from === to) {
      paths.push({ nodes: [from], confidence: 1.0 });
      return paths;
    }
    
    // TODO: pełna implementacja graph traversal
    return paths;
  }
  
  /**
   * Rejestruje publiczną tożsamość node'a
   */
  registerIdentity(identity: PublicIdentity): void {
    this.knownIdentities.set(identity.nodeId, identity);
    this.trustCache.delete(identity.nodeId);
  }
  
  private encodeLink(link: TrustLink): Uint8Array {
    const json = JSON.stringify({
      from: link.from,
      weight: link.weight,
      timestamp: link.timestamp.getTime()
    });
    return new TextEncoder().encode(json);
  }
  
  private logTrustUpdate(nodeId: string, delta: number, reason: string): void {
    // W produkcji: wysłać do audit log / gossip
    console.debug(`Trust update: ${nodeId} ${delta >= 0 ? '+' : ''}${delta.toFixed(3)} [${reason}]`);
  }
}

export interface TrustConfig {
  defaultTrust: number;           // Trust dla nieznanych node'ów (0.1-0.3)
  trustDecayPerDay: number;       // 0.01 = 1% decay dziennie
  minTrustToInvite: number;       // Node musi mieć >0.4 aby zapraszać
  maxTrustLinks: number;          // Limit linków na node (anti-sybil)
}

export interface TrustPath {

  confidence: number;             // 0.0-1.0, pewność ścieżki
}

export type TrustUpdateReason = 
  | 'task_success'
  | 'task_failure'
  | 'spam_detected'
  | 'invite_accepted'
  | 'gossip_validation'
  | 'manual_adjustment';

### 2.2 GossipEngine — Propagacja Mesh

```typescript
// network/GossipEngine.ts
import { NetworkAdapter, NetworkMessage, MessageHandler } from './NetworkAdapter';

/**
 * Silnik gossip — propaguje wiadomości w mesh network
 * 
 * Zasady:
 * - Każda wiadomość ma TTL i hopCount
 * - Deduplikacja po messageId
 * - Forward tylko do zaufanych peerów
 */
export class GossipEngine {
  private seenMessages: Set<string> = new Map(); // messageId -> timestamp
  private subscriptions: Map<string, Set<MessageHandler>> = new Map();
  
  constructor(
    private network: NetworkAdapter,
    private config: GossipConfig
  ) {}
  
  async init(): Promise<void> {
    // Subskrybuj gossip topic
    this.network.subscribe('gossip/propagate', this.handleGossip.bind(this));
    
    // Cleanup starych message IDs co godzinę
    setInterval(() => this.cleanupSeen(), 60 * 60 * 1000);
  }
  
  /**
   * Publikuje wiadomość do gossip network
   */
  async publish(message: NetworkMessage): Promise<void> {
    // Sign if not already signed
    if (!message.signature) {
      message.signature = await this.signMessage(message);
    }
    
    // Send to direct peers
    for (const peer of this.network.peers) {
      if (this.shouldForwardTo(peer, message)) {
        await this.network.send(peer.nodeId, message);
      }
    }
  }
  
  /**
   * Obsługa przychodzącej wiadomości gossip
   */
  private async handleGossip(message: NetworkMessage): Promise<void> {
    // Deduplikacja
    if (this.isSeen(message.id)) {
      return;
    }
    this.markSeen(message.id);
    
    // TTL check
    if (Date.now() - message.timestamp > message.ttl) {
      return;
    }
    
    // Trust check
    if (!this.isTrustedSource(message.from)) {
      return;
    }
    
    // Forward to other peers (zwiększ hopCount)
    if (message.hopCount < this.config.maxHops) {
      const forwarded = { ...message, hopCount: message.hopCount + 1 };
      for (const peer of this.network.peers) {
        if (peer.nodeId !== message.from && this.shouldForwardTo(peer, message)) {
          this.network.send(peer.nodeId, forwarded).catch(() => {});
        }
      }
    }
    
    // Deliver to local subscribers
    const handlers = this.subscriptions.get(message.type) || new Set();
    for (const handler of handlers) {
      handler(message).catch(err => console.error('Gossip handler error:', err));
    }
  }
  
  subscribe(messageType: string, handler: MessageHandler): UnsubscribeFn {
    if (!this.subscriptions.has(messageType)) {
      this.subscriptions.set(messageType, new Set());
    }
    this.subscriptions.get(messageType)!.add(handler);
    
    return () => {
      this.subscriptions.get(messageType)?.delete(handler);
    };
  }
  
  private shouldForwardTo(peer: PeerInfo, message: NetworkMessage): boolean {
    // Nie wysyłaj z powrotem do sendera
    if (peer.nodeId === message.from) return false;
    
    // Tylko do zaufanych
    if (peer.trustScore !== undefined && peer.trustScore < this.config.minTrustToForward) {
      return false;
    }
    
    // Filter by capabilities if message requires
    if (message.payload?.requiresCapability && !peer.capabilities.includes(message.payload.requiresCapability)) {
      return false;
    }
    
    return true;
  }
  
  private isTrustedSource(nodeId: string): boolean {
    // Delegacja do TrustManager w Node
    // Tutaj uproszczenie: accept if we know the peer
    return this.network.peers.some(p => p.nodeId === nodeId);
  }
  
  private isSeen(messageId: string): boolean {
    return this.seenMessages.has(messageId);
  }
  
  private markSeen(messageId: string): void {
    this.seenMessages.set(messageId, Date.now());
  }
  
  private cleanupSeen(): void {
    const cutoff = Date.now() - 24 * 60 * 60 * 1000; // 24h
    for (const [id, timestamp] of this.seenMessages) {
      if (timestamp < cutoff) {
        this.seenMessages.delete(id);
      }
    }
  }
  
  private async signMessage(message: NetworkMessage): Promise<string> {
    // Delegacja do Identity z Node
    // Placeholder
    return '';
  }
}

export interface GossipConfig {
  maxHops: number;              // Max propagation depth
  minTrustToForward: number;    // Only forward to trusted peers
  seenMessageTTL: number;       // How long to remember seen messages
}

### 3.1 Node — Host dla Modułów

```typescript
// node/Node.ts
import { StemCell } from '../core/StemCell';
import { Identity } from '../trust/Identity';
import { TrustManager, TrustConfig } from '../trust/TrustManager';
import { NetworkAdapter, NetworkConfig, NetworkMessage } from '../network/NetworkAdapter';
import { GossipEngine, GossipConfig } from '../network/GossipEngine';
import { EconomyEngine, EconomyConfig } from './EconomyEngine';
import { ModuleConfig, ModuleRole, NetworkEvent, Response } from '../types/core';
import { Logger } from '../utils/Logger';

/**
 * Node = kontener dla modułów + koordynator sieciowy
 * 
 * To jest "organizm" — StemCell to tylko "komórka"
 */
export class Node {
  readonly identity: Identity;
  readonly trustManager: TrustManager;
  readonly network: NetworkAdapter;
  readonly gossip: GossipEngine;
  readonly economy: EconomyEngine;
  
  private modules: Map<string, StemCell> = new Map();
  private logger: Logger;
  private running = false;
  
  constructor(
    identity: Identity,
    networkAdapter: NetworkAdapter,
    config: NodeConfig
  ) {
    this.identity = identity;
    this.network = networkAdapter;
    this.logger = new Logger(`node:${identity.nodeId}`, config.logLevel);
    
    this.trustManager = new TrustManager(identity, config.trust);
    this.gossip = new GossipEngine(networkAdapter, config.gossip);
    this.economy = new EconomyEngine(identity, config.economy);
    
    // Register self in trust manager
    this.trustManager.registerIdentity(identity.toPublicJSON());
  }
  
  /**
   * Bootstrap node — inicjalizacja wszystkich warstw
   */
  async bootstrap(config: NodeConfig): Promise<void> {
    this.logger.info('Bootstrapping node...');
    
    // Init network
    await this.network.init(config.network);
    this.logger.info('Network initialized');
    
    // Init gossip
    await this.gossip.init();
    this.logger.info('Gossip engine initialized');
    
    // Subscribe to system messages
    this.network.subscribe('node/announce', this.handleNodeAnnounce.bind(this));
    this.network.subscribe('task/delegate', this.handleTaskDelegation.bind(this));
    
    // Announce ourselves
    await this.announce();
    
    this.running = true;
    this.logger.info(`Node ${this.identity.nodeId} is running`);
  }
  
  /**
   * Join network via signed invite
   */
  async joinNetwork(signedInvite: SignedInvite): Promise<JoinResult> {
    // Verify invite
    const verification = await SignedInvite.verify(signedInvite, this.config.trust.minTrustToInvite);
    if (!verification.valid) {
      return { success: false, reason: verification.reason };
    }
    
    // Add trust link from inviter
    const trustLink: TrustLink = {
      from: signedInvite.payload.inviterNodeId,
      weight: 0.8, // High weight for direct invite
      timestamp: new Date(signedInvite.payload.timestamp),
      signature: signedInvite.signature
    };
    
    this.trustManager.addTrustLink(this.identity.nodeId, trustLink);
    this.trustManager.registerIdentity(signedInvite.inviterPublicIdentity);
    
    // Connect to inviter
    const inviterPeer = await this.discoverPeer(signedInvite.payload.inviterNodeId);
    if (inviterPeer) {
      await this.network.connect(inviterPeer);
    }
    
    return { success: true };
  }
  
  /**
   * Ładuje moduł do tego node'a
   */
  async loadModule<T extends StemCell>(
    ModuleClass: new (id?: string) => T,
    config: ModuleConfig
  ): Promise<string> {
    const module = new ModuleClass();
    await module.init(config);
    
    this.modules.set(module.moduleId, module);
    this.logger.info(`Loaded module ${module.moduleId}`);
    
    return module.moduleId;
  }
  
  /**
   * Deleguje zadanie do sieci (P2P spawn)
   */
  async delegateTask(
    task: TaskSpecification,
    criteria: PeerSelector
  ): Promise<DelegationResult> {
    // Find suitable peers
    const candidates = await this.network.findPeers(criteria, 3);
    
    if (candidates.length === 0) {
      // Fallback: execute locally if we have the module
      return await this.executeLocally(task);
    }
    
    // Select best peer by trust + capability
    const target = this.selectBestPeer(candidates, task);
    
    // Send task
    const message: NetworkMessage = {
      id: crypto.randomUUID(),
      from: this.identity.nodeId,
      to: target.nodeId,
      type: 'task/delegate',
      payload: task,
      timestamp: Date.now(),
      ttl: 5 * 60 * 1000, // 5 minutes
      hopCount: 0
    };
    
    const result = await this.network.send(target.nodeId, message);
    
    if (result.success && result.delivered) {
      // Track for economy
      this.economy.recordDelegation(task, target.nodeId);
      return { success: true, executedBy: target.nodeId };
    }
    
    // Fallback local
    return await this.executeLocally(task);
  }
  
  /**
   * Obsługa przychodzącego zadania
   */
  private async handleTaskDelegation(message: NetworkMessage): Promise<void> {
    const task = message.payload as TaskSpecification;
    
    // Trust check
    if (!this.trustManager.isTrusted(message.from, 0.3)) {
      this.logger.warn(`Rejected task from untrusted node: ${message.from}`);
      return;
    }
    
    // Find module that can handle this task
    const module = this.findModuleForTask(task);
    if (!module) {
      this.logger.warn(`No module found for task type: ${task.type}`);
      return;
    }
    
    // Execute
    const startTime = Date.now();
    try {
      const result = await module.communicate({
        type: task.eventType,
        source: message.from,
        payload: task.payload,
        timestamp: new Date(message.timestamp),
        priority: task.priority,
        ttl: message.ttl - (Date.now() - message.timestamp)
      });
      
      // Send result back
      await this.network.send(message.from, {
        id: crypto.randomUUID(),
        from: this.identity.nodeId,
        to: message.from,
        type: 'task/result',
        payload: { taskId: task.id, result, executionTime: Date.now() - startTime },
        timestamp: Date.now(),
        ttl: 60000,
        hopCount: 0
      });
      
      // Update trust + economy
      if (result.success) {
        this.trustManager.updateTrust(message.from, 0.02, 'task_success');
        this.economy.recordReward(message.from, task);
      }
      
    } catch (error) {
      this.logger.error('Task execution failed', error);
      this.trustManager.updateTrust(message.from, -0.05, 'task_failure');
    }
  }
  
  /**
   * Announce node to network
   */
  private async announce(): Promise<void> {
    const announcement: NetworkMessage = {
      id: crypto.randomUUID(),
      from: this.identity.nodeId,
      type: 'node/announce',
      payload: {
        identity: this.identity.toPublicJSON(),
        capabilities: ['compute', 'storage'],
        load: this.getLoadMetrics()
      },
      timestamp: Date.now(),
      ttl: 30 * 60 * 1000,
      hopCount: 0
    };
    
    this.gossip.publish(announcement);
  }
  
  private async handleNodeAnnounce(message: NetworkMessage): Promise<void> {
    const { identity, capabilities } = message.payload;
    
    // Register in trust manager
    this.trustManager.registerIdentity(identity);
    
    // Maybe connect if trusted and useful
    if (identity.trustScore > this.config.trust.minTrustToInvite) {
      const peer: PeerInfo = {
        nodeId: identity.nodeId,
        multiaddr: message.payload.multiaddr,
        publicKey: identity.publicKey,
        capabilities,
        lastSeen: new Date(message.timestamp),
        trustScore: identity.trustScore
      };
      
      // Soft connect (don't wait)
      this.network.connect(peer).catch(() => {});
    }
  }
  
  private findModuleForTask(task: TaskSpecification): StemCell | undefined {
    // Simple: find first module that specializes in this role
    for (const module of this.modules.values()) {
      if (module.canHandleTask?.(task)) {
        return module;
      }
    }
    return undefined;
  }
  
  private selectBestPeer(peers: PeerInfo[], task: TaskSpecification): PeerInfo {
    // Score = trust * capability_match * (1 - load)
    return peers.reduce((best, peer) => {
      const score = (peer.trustScore || 0.5) 
        * this.capabilityMatch(peer.capabilities, task.requires)
        * (1 - (peer.load || 0));
      
      const bestScore = (best.trustScore || 0.5)
        * this.capabilityMatch(best.capabilities, task.requires)
        * (1 - (best.load || 0));
      
      return score > bestScore ? peer : best;
    });
  }
  
  private capabilityMatch(capabilities: string[], requires: string[]): number {
    if (requires.length === 0) return 1;
    const matches = requires.filter(r => capabilities.includes(r)).length;
    return matches / requires.length;
  }
  
  private getLoadMetrics(): LoadMetrics {
    // Aggregate from all modules
    let totalCpu = 0, totalMem = 0, activeTasks = 0;
    
    for (const module of this.modules.values()) {
      const health = module.healthcheck();
      totalCpu += health.cpuUsage;
      totalMem += health.memoryUsage;
      activeTasks += health.activeTasks;
    }
    
    return {
      cpuLoad: totalCpu / this.modules.size,
      memoryLoad: totalMem,
      activeTasks,
      moduleCount: this.modules.size
    };
  }
  
  async shutdown(): Promise<void> {
    this.running = false;
    
    // Shutdown all modules
    for (const module of this.modules.values()) {
      await module.shutdown();
    }
    
    await this.gossip.shutdown?.();
    await this.network.shutdown();
    
    this.logger.info('Node shut down');
  }
  
  healthcheck(): NodeHealth {
    return {
      nodeId: this.identity.nodeId,
      running: this.running,
      trustScore: this.identity.trustScore,
      peerCount: this.network.peers.length,
      moduleCount: this.modules.size,
      load: this.getLoadMetrics(),
      reputation: this.identity.reputation
    };
  }
}

      balance: 0,
      earned: 0,
      spent: 0,
      joyContributed: 0,
      lastUpdated: new Date()
    });
  }
  
  /**
   * Rejestruje delegację zadania (koszt)
   */
  recordDelegation(task: TaskSpecification, executor: string): void {
    const cost = this.calculateCost(task);
    
    const account = this.accounts.get(this.ownIdentity.nodeId);
    if (account) {
      account.spent += cost;
      account.lastUpdated = new Date();
    }
    
    // Track executor's potential earnings (pending confirmation)
    if (!this.accounts.has(executor)) {
      this.accounts.set(executor, this.createEmptyAccount(executor));
    }
  }
  
  /**
   * Rejestruje nagrodę za wykonane zadanie
   */
  recordReward(from: string, task: TaskSpecification): void {
    const reward = this.calculateReward(task, from);
    
    const account = this.accounts.get(from);
    if (account) {
      account.earned += reward;
      account.balance += reward;
      account.joyContributed += reward * this.config.joyFactor;
      account.lastUpdated = new Date();
    }
  }
  
  /**
   * Oblicza koszt zadania
   */
  private calculateCost(task: TaskSpecification): number {
    // Prosty model: base + complexity × resource_estimate
    const base = this.config.baseCost;
    const complexity = task.payload?.complexity || 1;
    const resourceFactor = task.requires?.length || 1;
    
    return base * complexity * resourceFactor;
  }
  
  /**
   * Oblicza nagrodę
   */
  private calculateReward(task: TaskSpecification, executor: string): number {
    const baseReward = this.calculateCost(task);
    
    // Bonus za zaufanie executora
    const trustBonus = 1 + (this.config.trustBonusFactor * 0.5); // Placeholder
    
    // Joy factor: zadania z wyższym joy_index = wyższa nagroda
    const joyFactor = task.payload?.joyIndex || 1;
    
    return baseReward * trustBonus * joyFactor;
  }
  
  /**
   * Pobiera stan konta
   */
  getAccount(nodeId: string): Account | undefined {
    return this.accounts.get(nodeId);
  }
  
  /**
   * Lista top contributors (do reputacji)
   */
  getTopContributors(limit: number = 10): Account[] {
    return Array.from(this.accounts.values())
      .sort((a, b) => b.joyContributed - a.joyContributed)
      .slice(0, limit);
  }
  
  private createEmptyAccount(nodeId: string): Account {
    return {
      nodeId,
      balance: 0,
      earned: 0,
      spent: 0,
      joyContributed: 0,
      lastUpdated: new Date()
    };
  }
}

export interface EconomyConfig {
  baseCost: number;              // Base cost per task
  trustBonusFactor: number;      // Multiplier for trusted executors
  joyFactor: number;             // Weight of joy_index in rewards
  decayPerDay: number;           // Optional: balance decay for inactivity
}

export interface Account {
  nodeId: string;
  balance: number;               // Current happycoin balance
  earned: number;                // Lifetime earned
  spent: number;                 // Lifetime spent
  joyContributed: number;        // Weighted by joy_factor
  lastUpdated: Date;
}

/**
 * Identity — kryptograficzna tożsamość węzła P2P 60-24
 * 
 * @module trust/Identity
 * @version 0.2.0
 * @since 2026-03
 */

import { ed25519 } from '@noble/ed25519';
import { sha3_256 } from '@noble/hashes/sha3';

// ============================================================================
// TYPES
// ============================================================================

export interface ReputationMetrics {
  /** Liczba zadań zakończonych sukcesem */
  tasksCompleted: number;
  /** Liczba zadań zakończonych błędem */
  tasksFailed: number;
  /** Wkład w radość sieci (joy_index accumulator) */
  joyContributed: number;
  /** Ostatnia aktywność */
  lastActive: Date;
}

export interface TrustLink {
  /** NodeID węzła, który mnie zaprosił */
  from: string;
  /** Waga tego zaproszenia (0.0 - 1.0) */
  weight: number;
  /** Czas utworzenia linku */
  timestamp: Date;
  /** Podpis kryptograficzny zapraszającego */
  signature: Uint8Array;
}

export interface PublicIdentity {
  /** Unikalny identyfikator węzła */
  nodeId: string;
  /** Public key w formacie hex */
  publicKey: string;
  /** Aktualny score zaufania (0.0 - 1.0) */
  trustScore: number;
  /** Lista trust linków (kto mnie zaprosił) */
  trustLinks: Array<{
    from: string;
    weight: number;
    timestamp: string; // ISO string
  }>;
  /** Metryki reputacji */
  reputation: ReputationMetrics;
}

// ============================================================================
// IDENTITY CLASS
// ============================================================================

/**
 * Reprezentuje tożsamość kryptograficzną węzła.
 * 
 * @remarks
 * - privateKey NIGDY nie opuszcza pamięci tej instancji
 * - NodeID jest deterministyczny: SHA3-256(publicKey).slice(0,32)
 * - Wszystkie operacje signing/verifying są async (crypto)
 * 
 * @example
 * ```typescript
 * const identity = await Identity.generate();
 * console.log('My NodeID:', identity.nodeId);
 * 
 * const message = new TextEncoder().encode('hello');
 * const sig = await identity.sign(message);
 * const valid = await Identity.verify(message, sig, identity.publicKey);
 * ```
 */
export class Identity {
  /** Unikalny identyfikator węzła (32 znaki hex) */
  readonly nodeId: string;
  
  /** Public key — można bezpiecznie udostępniać */
  readonly publicKey: Uint8Array;
  
  /** Private key — trzymać w tajemnicy, nigdy nie serializować */
  private readonly privateKey: Uint8Array;
  
  /** Dynamiczny score zaufania (aktualizowany przez TrustManager) */
  trustScore: number = 0.5; // Start z neutralnym zaufaniem
  
  /** Lista węzłów, które mnie zaprosiły (Web of Trust) */
  trustLinks: TrustLink[] = [];
  
  /** Metryki reputacji — aktualizowane po każdej interakcji */
  reputation: ReputationMetrics = {
    tasksCompleted: 0,
    tasksFailed: 0,
    joyContributed: 0,
    lastActive: new Date()
  };

  // ============================================================================
  // CONSTRUCTORS
  // ============================================================================

  private constructor(
    publicKey: Uint8Array,
    privateKey: Uint8Array
  ) {
    this.publicKey = publicKey;
    this.privateKey = privateKey;
    this.nodeId = this.computeNodeId(publicKey);
  }

  /**
   * Generuje NOWĄ tożsamość z losową parą kluczy.
   * 
   * @returns Promise z nową instancją Identity
   * 
   * @example
   * ```typescript
   * const identity = await Identity.generate();
   * await saveIdentityToStorage(identity); // Tylko public + encrypted private
   * ```
   */
  static async generate(): Promise<Identity> {
    const privateKey = ed25519.utils.randomPrivateKey();
    const publicKey = await ed25519.getPublicKey(privateKey);
    return new Identity(publicKey, privateKey);
  }

  /**
   * Ładuje istniejącą tożsamość z zapisanych kluczy.
   * 
   * @param publicKey - Public key jako Uint8Array lub hex string
   * @param privateKey - Private key jako Uint8Array lub hex string
   * @returns Promise z załadowaną instancją Identity
   * 
   * @example
   * ```typescript
   * const keys = await loadKeysFromSecureStorage();
   * const identity = await Identity.load(keys.public, keys.private);
   * ```
   */
  static async load(
    publicKey: string | Uint8Array,
    privateKey: string | Uint8Array
  ): Promise<Identity> {
    const pubKey = typeof publicKey === 'string' 
      ? hexToBytes(publicKey) 
      : publicKey;
    const privKey = typeof privateKey === 'string' 
      ? hexToBytes(privateKey) 
      : privateKey;
    
    return new Identity(pubKey, privKey);
  }

  // ============================================================================
  // CORE METHODS
  // ============================================================================

  /**
   * Oblicza NodeID z public key: SHA3-256(pubKey).slice(0,32)
   */
  private computeNodeId(publicKey: Uint8Array): string {
    const hash = sha3_256(publicKey);
    return bytesToHex(hash).slice(0, 32);
  }

  /**
   * Podpisuje dowolną wiadomość using ed25519.
   * 
   * @param message - Wiadomość jako Uint8Array
   * @returns Promise z podpisem jako Uint8Array
   * 
   * @example
   * ```typescript
   * const payload = new TextEncoder().encode(JSON.stringify(data));
   * const signature = await identity.sign(payload);
   * ```
   */
  async sign(message: Uint8Array): Promise<Uint8Array> {
    return await ed25519.sign(message, this.privateKey);
  }

  /**
   * Weryfikuje podpis (statyczna metoda — nie potrzebuje privateKey).
   * 
   * @param message - Oryginalna wiadomość
   * @param signature - Podpis do weryfikacji
   * @param publicKey - Public key signer'a
   * @returns Promise<boolean> — true jeśli podpis jest valid
   * 
   * @example
   * ```typescript
   * const valid = await Identity.verify(msg, sig, signerPublicKey);
   * if (!valid) throw new Error('Invalid signature');
   * ```
   */
  static async verify(
    message: Uint8Array,
    signature: Uint8Array,
    publicKey: Uint8Array
  ): Promise<boolean> {
    return await ed25519.verify(signature, message, publicKey);
  }

  /**
   * Serializuje PUBLICZNĄ część tożsamości (bez privateKey!).
   * 
   * @returns PublicIdentity — bezpieczne do wysłania przez sieć
   * 
   * @example
   * ```typescript
   * const publicInfo = identity.toPublicJSON();
   * await network.broadcast({ type: 'node/announce', payload: publicInfo });
   * ```
   */
  toPublicJSON(): PublicIdentity {
    return {
      nodeId: this.nodeId,
      publicKey: bytesToHex(this.publicKey),
      trustScore: this.trustScore,
      trustLinks: this.trustLinks.map(link => ({
        from: link.from,
        weight: link.weight,
        timestamp: link.timestamp.toISOString()
      })),
      reputation: {
        ...this.reputation,
        lastActive: this.reputation.lastActive
      }
    };
  }

  /**
   * Aktualizuje reputację po interakcji.
   * 
   * @param success - Czy interakcja się powiodła
   * @param joyDelta - Zmiana w joy_index (może być ujemna)
   */
  updateReputation(success: boolean, joyDelta: number = 0): void {
    if (success) {
      this.reputation.tasksCompleted++;
    } else {
      this.reputation.tasksFailed++;
    }
    this.reputation.joyContributed += joyDelta;
    this.reputation.lastActive = new Date();
  }

  // ============================================================================
  // SECURITY
  // ============================================================================

  /**
   * Bezpiecznie zeruje privateKey z pamięci.
   * 
   * @remarks
   * Wywołać przed usunięciem instancji, jeśli privateKey była wrażliwa.
   * Nie gwarantuje 100% usunięcia z pamięci (GC), ale minimalizuje ryzyko.
   */
  secureWipe(): void {
    // Zero out privateKey buffer
    this.privateKey.fill(0);
  }
}

// ============================================================================
// UTILS
// ============================================================================

function bytesToHex(bytes: Uint8Array): string {
  return Array.from(bytes)
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
}

function hexToBytes(hex: string): Uint8Array {
  if (hex.startsWith('0x')) hex = hex.slice(2);
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < hex.length; i += 2) {
    bytes[i / 2] = parseInt(hex.slice(i, i + 2), 16);
  }
  return bytes;
}

```typescript
/**
 * SignedInvite — protokół zaproszeń do sieci P2P 60-24
 * 
 * @module trust/SignedInvite
 * @version 0.2.0
 */

import { Identity, PublicIdentity, TrustLink } from './Identity';

// ============================================================================
// TYPES
// ============================================================================

export interface InvitePayload {
  /** NodeID węzła zapraszającego */
  inviterNodeId: string;
  /** Public key (hex) zapraszanego węzła */
  inviteePublicKey: string;
  /** Unix timestamp w ms */
  timestamp: number;
  /** Anti-replay nonce */
  nonce: string;
  /** Dozwolone capabilities dla nowego node'a */
  capabilities: string[];
  /** Dodatkowe metadata (opcjonalne) */
  metadata?: Record<string, any>;
}

export interface VerificationResult {
  /** Czy invite jest valid */
  valid: boolean;
  /** Powód odrzucenia (jeśli !valid) */
  reason?: string;
  /** Trust score invitera (dla debug) */
  inviterTrust?: number;
}

// ============================================================================
// SIGNED INVITE CLASS
// ============================================================================

/**
 * Reprezentuje kryptograficznie podpisane zaproszenie do sieci.
 * 
 * @remarks
 * Flow:
 * 1. Alice (znany node) chce zaprosić Boba
 * 2. Alice tworzy SignedInvite z public key Boba
 * 3. Alice podpisuje invite swoim privateKey
 * 4. Bob otrzymuje invite i wysyła go do sieci przy join
 * 5. Każdy node weryfikuje: podpis + trust invitera + czas
 * 
 * @example
 * ```typescript
 * // Alice tworzy invite
 * const invite = await SignedInvite.create(
 *   aliceIdentity,
 *   bobIdentity.publicKey,
 *   { capabilities: ['compute', 'storage'] }
 * );
 * 
 * // Bob weryfikuje przed użyciem
 * const result = await SignedInvite.verify(invite, 0.3);
 * if (!result.valid) throw new Error(result.reason);
 * 
 * // Bob używa invite do joinowania sieci
 * await bobNode.joinNetwork(invite);
 * ```
 */
export class SignedInvite {
  constructor(
    /** Payload zaproszenia */
    public readonly payload: InvitePayload,
    /** Podpis kryptograficzny invitera */
    public readonly signature: Uint8Array,
    /** Publiczna tożsamość invitera (do weryfikacji) */
    public readonly inviterPublicIdentity: PublicIdentity
  ) {}

  // ============================================================================
  // FACTORY METHODS
  // ============================================================================

  /**
   * Tworzy NOWE zaproszenie (tylko inviter może to zrobić).
   * 
   * @param inviter - Identity węzła zapraszającego
   * @param inviteePublicKey - Public key zapraszanego węzła
   * @param options - Dodatkowe opcje zaproszenia
   * @returns Promise z nowym SignedInvite
   */
  static async create(
    inviter: Identity,
    inviteePublicKey: Uint8Array,
    options?: Partial<InvitePayload>
  ): Promise<SignedInvite> {
    const payload: InvitePayload = {
      inviterNodeId: inviter.nodeId,
      inviteePublicKey: bytesToHex(inviteePublicKey),
      timestamp: Date.now(),
      nonce: crypto.randomUUID(),
      capabilities: options?.capabilities || ['compute', 'storage'],
      metadata: options?.metadata,
      ...options
    };

    const message = SignedInvite.encodePayload(payload);
    const signature = await inviter.sign(message);

    return new SignedInvite(
      payload,
      signature,
      inviter.toPublicJSON()
    );
  }

  // ============================================================================
  // VERIFICATION
  // ============================================================================

  /**
   * Weryfikuje zaproszenie (każdy node może to zrobić).
   * 
   * @param invite - Zaproszenie do weryfikacji
   * @param trustThreshold - Minimalny trust invitera (default: 0.3)
   * @returns VerificationResult z wynikiem i ew. powodem odrzucenia
   */
  static async verify(
    invite: SignedInvite,
    trustThreshold: number = 0.3
  ): Promise<VerificationResult> {
    // 1. Weryfikacja podpisu kryptograficznego
    const message = this.encodePayload(invite.payload);
    const publicKey = hexToBytes(invite.inviterPublicIdentity.publicKey);
    
    const signatureValid = await Identity.verify(
      message,
      invite.signature,
      publicKey
    );
    
    if (!signatureValid) {
      return { valid: false, reason: 'INVALID_SIGNATURE' };
    }

    // 2. Weryfikacja czasu (max 24h na wykorzystanie invite)
    const age = Date.now() - invite.payload.timestamp;
    const MAX_AGE_MS = 24 * 60 * 60 * 1000;
    if (age > MAX_AGE_MS) {
      return { valid: false, reason: 'INVITE_EXPIRED' };
    }

    // 3. Weryfikacja trust invitera
    if (invite.inviterPublicIdentity.trustScore < trustThreshold) {
      return { 
        valid: false, 
        reason: 'INVITER_LOW_TRUST',
        inviterTrust: invite.inviterPublicIdentity.trustScore
      };
    }

    // 4. Weryfikacja nonce (anti-replay) — sprawdzana przez Node
    // (tutaj tylko strukturalnie)
    if (!invite.payload.nonce || invite.payload.nonce.length < 32) {
      return { valid: false, reason: 'INVALID_NONCE' };
    }

    return { valid: true };
  }

  /**
   * Tworzy TrustLink z tego invite (po pomyślnej weryfikacji).
   * 
   * @returns TrustLink gotowy do dodania w TrustManager
   */
  toTrustLink(): TrustLink {
    return {
      from: this.payload.inviterNodeId,
      weight: 0.8, // High weight for direct invite
      timestamp: new Date(this.payload.timestamp),
      signature: this.signature
    };
  }

  // ============================================================================
  // UTILS
  // ============================================================================

  /**
   * Encodes payload to canonical JSON for signing/verification.
   * 
   * @remarks
   * Klucze są sortowane alfabetycznie dla deterministycznego hash.
   */
  private static encodePayload(payload: InvitePayload): Uint8Array {
    const sorted = Object.keys(payload).sort().reduce((acc, key) => {
      acc[key] = payload[key as keyof InvitePayload];
      return acc;
    }, {} as Record<string, any>);
    
    const json = JSON.stringify(sorted);
    return new TextEncoder().encode(json);
  }
}

// ============================================================================
// UTILS (shared with Identity.ts)
// ============================================================================

function bytesToHex(bytes: Uint8Array): string {
  return Array.from(bytes)
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
}

function hexToBytes(hex: string): Uint8Array {
  if (hex.startsWith('0x')) hex = hex.slice(2);
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < hex.length; i += 2) {
    bytes[i / 2] = parseInt(hex.slice(i, i + 2), 16);
  }
  return bytes;
}

```typescript
/**
 * TrustManager — silnik Web of Trust dla P2P 60-24
 * 
 * @module trust/TrustManager
 * @version 0.2.0
 */

import { Identity, PublicIdentity, TrustLink, ReputationMetrics } from './Identity';

// ============================================================================
// CONFIG & TYPES
// ============================================================================

export interface TrustConfig {
  /** Domyślny trust dla nieznanych node'ów (0.1-0.3) */
  defaultTrust: number;
  /** Decay zaufania dziennie (0.01 = 1%) */
  trustDecayPerDay: number;
  /** Minimalny trust aby móc zapraszać innych */
  minTrustToInvite: number;
  /** Maksymalna liczba trust linków na node (anti-Sybil) */
  maxTrustLinks: number;
  /** Threshold dla komunikacji (node z niższym trust = ograniczony access) */
  trustThresholdForCommunication: number;
}

export interface TrustPath {
  /** Chain of nodeIds od source do target */
  nodes: string[];
  /** Pewność ścieżki (0.0-1.0) */
  confidence: number;
}

export type TrustUpdateReason = 
  | 'task_success'
  | 'task_failure' 
  | 'spam_detected'
  | 'invite_accepted'
  | 'gossip_validation'
  | 'manual_adjustment'
  | 'joy_contribution';

// ============================================================================
// TRUST MANAGER CLASS
// ============================================================================

/**
 * Zarządza zaufaniem w sieci P2P 60-24.
 * 
 * @remarks
 * Model zaufania:
 * - Trust = weighted average trust od inviterów
 * - Decay: -1% dziennie bez aktywności
 * - Threshold gating: node z trust < 0.2 ma ograniczony access
 * 
 * @example
 * ```typescript
 * const trustManager = new TrustManager(myIdentity, defaultTrustConfig);
 * 
 * // Czy node jest zaufany?
 * if (trustManager.isTrusted('some-node-id')) {
 *   // Process message
 * }
 * 
 * // Aktualizuj trust po interakcji
 * trustManager.updateTrust('node-123', 0.02, 'task_success');
 * 
 * // Dodaj trust link po weryfikacji invite
 * trustManager.addTrustLink('new-node', signedInvite.toTrustLink());
 * ```
 */
export class TrustManager {
  /** Cache obliczonych trust scores (invalidate przy zmianach) */
  private trustCache: Map<string, { score: number; timestamp: number }> = new Map();
  
  /** Zarejestrowane publiczne tożsamości */
  private knownIdentities: Map<string, PublicIdentity> = new Map();
  
  /** Log trust updates (dla audytu/debug) */
  private auditLog: TrustAuditEntry[] = [];

  constructor(
    /** Własna tożsamość tego node'a */
    private readonly ownIdentity: Identity,
    /** Konfiguracja behawioru trust */
    private readonly config: TrustConfig
  ) {
    // Register self as fully trusted
    this.registerIdentity(ownIdentity.toPublicJSON());
  }

  // ============================================================================
  // PUBLIC API: TRUST QUERIES
  // ============================================================================

  /**
   * Czy node jest zaufany do komunikacji?
   * 
   * @param nodeId - NodeID do sprawdzenia
   * @param minScore - Opcjonalny minimalny score (override config)
   * @returns boolean
   */
  isTrusted(nodeId: string, minScore?: number): boolean {
    const threshold = minScore ?? this.config.trustThresholdForCommunication;
    return this.getTrustScore(nodeId) >= threshold;
  }

  /**
   * Oblicza trust score dla node'a (z cache + decay).
   * 
   * @param nodeId - NodeID do oceny
   * @returns number 0.0 - 1.0
   */
  getTrustScore(nodeId: string): number {
    // Check cache (valid for 5 minutes)
    const cached = this.trustCache.get(nodeId);
    if (cached && Date.now() - cached.timestamp < 5 * 60 * 1000) {
      return cached.score;
    }

    const identity = this.knownIdentities.get(nodeId);
    
    // Unknown node = default trust
    if (!identity) {
      const score = this.config.defaultTrust;
      this.cacheScore(nodeId, score);
      return score;
    }

    // Genesis node (no trust links) = default trust
    if (identity.trustLinks.length === 0) {
      const score = identity.nodeId === this.ownIdentity.nodeId ? 1.0 : this.config.defaultTrust;
      this.cacheScore(nodeId, score);
      return score;
    }

    // Weighted average: Σ(weight * inviter_trust) / Σ(weight)
    let weightedSum = 0;
    let weightTotal = 0;

    for (const link of identity.trustLinks) {
      const inviterTrust = this.getTrustScore(link.from); // Recursive!
      weightedSum += link.weight * inviterTrust;
      weightTotal += link.weight;
    }

    let score = weightTotal > 0 ? weightedSum / weightTotal : this.config.defaultTrust;

    // Apply decay based on inactivity
    const daysInactive = (Date.now() - identity.reputation.lastActive.getTime()) / (1000 * 60 * 60 * 24);
    score *= Math.pow(1 - this.config.trustDecayPerDay, daysInactive);

    // Clamp to [0, 1]
    score = Math.max(0, Math.min(1, score));

    this.cacheScore(nodeId, score);
    return score;
  }

  /**
   * Znajduje ścieżkę zaufania między node'ami (BFS).
   * 
   * @param from - Source NodeID
   * @param to - Target NodeID  
   * @param maxHops - Maksymalna długość ścieżki
   * @returns Array of TrustPath (może być pusty)
   */
  findTrustPath(from: string, to: string, maxHops: number = 3): TrustPath[] {
    if (from === to) {
      return [{ nodes: [from], confidence: 1.0 }];
    }

    const paths: TrustPath[] = [];
    const queue: Array<{ node: string; path: string[]; confidence: number }> = [
      { node: from, path: [from], confidence: 1.0 }
    ];
    const visited = new Set<string>([from]);

    while (queue.length > 0 && paths.length < 5) { // Limit results
      const { node, path, confidence } = queue.shift()!;
      
      if (path.length > maxHops) continue;

      const identity = this.knownIdentities.get(node);
      if (!identity) continue;

      for (const link of identity.trustLinks) {
        if (visited.has(link.from)) continue;
        
        const newConfidence = confidence * link.weight * (this.getTrustScore(link.from) || 0.5);
        const newPath = [...path, link.from];

        if (link.from === to) {
          paths.push({ nodes: newPath, confidence: newConfidence });
        } else {
          visited.add(link.from);
          queue.push({ node: link.from, path: newPath, confidence: newConfidence });
        }
      }
    }

    // Sort by confidence descending
    return paths.sort((a, b) => b.confidence - a.confidence);
  }

  // ============================================================================
  // PUBLIC API: TRUST MUTATIONS
  // ============================================================================

  /**
   * Aktualizuje trust score po interakcji.
   * 
   * @param nodeId - NodeID do aktualizacji
   * @param delta - Zmiana trust (-0.1 do +0.05 typowo)
   * @param reason - Powód aktualizacji (dla audytu)
   */
  updateTrust(nodeId: string, delta: number, reason: TrustUpdateReason): void {
    const identity = this.knownIdentities.get(nodeId);
    if (!identity) return;

    // Clamp delta do rozsądnych wartości (anti-manipulation)
    const clampedDelta = Math.max(-0.1, Math.min(0.05, delta));
    
    const oldScore = identity.trustScore;
    identity.trustScore = Math.max(0, Math.min(1, oldScore + clampedDelta));
    identity.reputation.lastActive = new Date();

    // Log for audit
    this.logAuditEntry(nodeId, oldScore, identity.trustScore, reason);

    // Invalidate cache
    this.trustCache.delete(nodeId);
    // Also invalidate dependents (simple: clear all)
    if (Math.abs(clampedDelta) > 0.01) {
      this.trustCache.clear();
    }
  }

  /**
   * Dodaje nowy trust link (po weryfikacji SignedInvite).
   * 
   * @param nodeId - NodeID do którego dodajemy link
   * @param link - TrustLink do dodania
   * @returns boolean — czy dodano sukcesem
   */
  addTrustLink(nodeId: string, link: TrustLink): boolean {
    // Verify link signature
    const linkValid = Identity.verify(
      this.encodeTrustLink(link),
      link.signature,
      hexToBytes(link.from)
    );
    
    if (!linkValid) return false;

    const identity = this.knownIdentities.get(nodeId);
    if (!identity) return false;

    // Anti-Sybil: limit trust links per node
    if (identity.trustLinks.length >= this.config.maxTrustLinks) {
      // Remove oldest if at limit
      identity.trustLinks.sort((a, b) => a.timestamp.getTime() - b.timestamp.getTime());
      identity.trustLinks.shift();
    }

    identity.trustLinks.push(link);
    this.trustCache.delete(nodeId);
    
    this.logAuditEntry(nodeId, identity.trustScore, identity.trustScore, 'invite_accepted');
    
    return true;
  }

  /**
   * Rejestruje publiczną tożsamość node'a w managerze.
   * 
   * @param identity - PublicIdentity do zarejestrowania
   */
  registerIdentity(identity: PublicIdentity): void {
    this.knownIdentities.set(identity.nodeId, identity);
    this.trustCache.delete(identity.nodeId);
  }

  /**
   * Pobiera zarejestrowaną tożsamość (jeśli znana).
   */
  getIdentity(nodeId: string): PublicIdentity | undefined {
    return this.knownIdentities.get(nodeId);
  }

  /**
   * Lista node'ów posortowana po trust score (do UI / discovery).
   */
  getTrustedNodes(minScore: number = 0.3): PublicIdentity[] {
    return Array.from(this.knownIdentities.values())
      .filter(id => this.getTrustScore(id.nodeId) >= minScore)
      .sort((a, b) => this.getTrustScore(b.nodeId) - this.getTrustScore(a.nodeId));
  }

  // ============================================================================
  // INTERNALS
  // ============================================================================

  private cacheScore(nodeId: string, score: number): void {
    this.trustCache.set(nodeId, { score, timestamp: Date.now() });
  }

  private encodeTrustLink(link: TrustLink): Uint8Array {
    const data = {
      from: link.from,
      weight: link.weight,
      timestamp: link.timestamp.getTime()
    };
    return new TextEncoder().encode(JSON.stringify(data));
  }

  private logAuditEntry(
    nodeId: string,
    oldScore: number,
    newScore: number,
    reason: TrustUpdateReason
  ): void {
    const entry: TrustAuditEntry = {
      timestamp: new Date(),
      nodeId,
      oldScore,
      newScore,
      delta: newScore - oldScore,
      reason
    };
    
    this.auditLog.push(entry);
    
    // Keep log bounded
    if (this.auditLog.length > 1000) {
      this.auditLog.shift();
    }
    
    // In production: emit to gossip / persistent storage
    console.debug(`[TrustAudit] ${nodeId}: ${oldScore.toFixed(3)} → ${newScore.toFixed(3)} [${reason}]`);
  }

  /**
   * Eksportuje audit log (dla debug / monitoring).
   */
  getAuditLog(since?: Date): TrustAuditEntry[] {
    if (!since) return [...this.auditLog];
    return this.auditLog.filter(e => e.timestamp >= since);
  }
}

export interface TrustAuditEntry {
  timestamp: Date;
  nodeId: string;
  oldScore: number;
  newScore: number;
  delta: number;
  reason: TrustUpdateReason;
}

// ============================================================================
// UTILS
// ============================================================================

function hexToBytes(hex: string): Uint8Array {
  if (hex.startsWith('0x')) hex = hex.slice(2);
  const bytes = new Uint8Array(hex.length / 2);
  for (let i = 0; i < hex.length; i += 2) {
    bytes[i / 2] = parseInt(hex.slice(i, i + 2), 16);
  }
  return bytes;
}

      expect(decayedScore).toBeGreaterThan(0.5);
    });
  });

  describe('Anti-Sybil', () => {
    it('should limit trust links per node', async () => {
      const target = await Identity.generate();
      manager.registerIdentity(target.toPublicJSON());
      
      // Add maxTrustLinks + 1 invites from different inviters
      for (let i = 0; i < defaultConfig.maxTrustLinks + 1; i++) {
        const inviter = await Identity.generate();
        inviter.trustScore = 0.9;
        manager.registerIdentity(inviter.toPublicJSON());
        
        const invite = await SignedInvite.create(inviter, target.publicKey);
        manager.addTrustLink(target.nodeId, invite.toTrustLink());
      }
      
      // Should have at most maxTrustLinks
      const registered = manager.getIdentity(target.nodeId);
      expect(registered?.trustLinks.length).toBeLessThanOrEqual(defaultConfig.maxTrustLinks);
    });
  });

  describe('Audit logging', () => {
    it('should log trust updates', () => {
      const node = 'audit-test';
      manager.registerIdentity({ ...root.toPublicJSON(), nodeId: node });
      
      manager.updateTrust(node, 0.02, 'task_success');
      
      const log = manager.getAuditLog();
      expect(log.length).toBeGreaterThan(0);
      expect(log[log.length - 1]).toMatchObject({
        nodeId: node,
        reason: 'task_success',

      });
    });

# Trust Layer — Dokumentacja

## Przegląd

Trust Layer to fundament bezpieczeństwa i emergencji w P2P 60-24. Zapewnia:

1. **Kryptograficzną tożsamość** — każdy node ma unikalny, weryfikowalny ID
2. **Web of Trust** — zaufanie propaguje się przez sieć, nie jest centralne
3. **Anti-Sybil** — mechanizmy ograniczające tworzenie fake node'ów
4. **Dynamiczny scoring** — trust rośnie i maleje w zależności od zachowania

## Komponenty

### Identity

```typescript

// → { nodeId: 'a1b2c3...', publicKey: Uint8Array, ... }

// Signing

// Verification (static)

```

### SignedInvite

```typescript

  inviterIdentity,
  inviteePublicKey,
  { capabilities: ['compute'] }

// Verify (any node)

if (!result.valid) throw new Error(result.reason);
```

### TrustManager

```typescript

// Add trust link from verified invite

```

## Model Zaufania

### Obliczanie Trust Score

```
trust(node) = 
  if no links: defaultTrust
  else: Σ(link.weight × trust(inviter)) / Σ(link.weight)
  then: apply decay based on inactivity
```

### Decay

- Codziennie: `trust *= (1 - trustDecayPerDay)`
- Aktywność resetuje licznik inactivity
- Zapobiega "zombie nodes" z historycznym trust

### Thresholds

| Parametr | Default | Znaczenie |
|----------|---------|-----------|
| `defaultTrust` | 0.2 | Trust dla nieznanych node'ów |
| `trustThresholdForCommunication` | 0.3 | Minimalny trust do komunikacji |
| `minTrustToInvite` | 0.4 | Minimalny trust aby zapraszać innych |

## Bezpieczeństwo

### Ochrona przed atakami

1. **Spoofing** → ed25519 signatures na wszystkich invite'ach
2. **Sybil** → limit trust linków + weighted propagation
3. **Replay** → nonce + timestamp w SignedInvite
4. **Manipulacja trust** → clamp delta + audit log

### Best Practices

```typescript

if (!verification.valid) { /* reject */ }

// Nie ufaj "na słowo" — zawsze sprawdzaj isTrusted()
if (!trustManager.isTrusted(event.source)) { /* drop */ }
```

  publicKey: string; // hex

  | 'node/announce'
  | 'node/handshake'
  | 'task/delegate'
  | 'task/result'
  | 'trust/update'
  | 'gossip/propagate'
  | 'memory/sync'
  | 'system/heartbeat';

  to?: NodeId;           // undefined = broadcast

```typescript
/**
 * Mock adapter sieciowy — symuluje zachowanie P2P do testów
 * @module network/MockNetworkAdapter
 */

import { NetworkAdapter } from './NetworkAdapter';
import {
  NetworkConfig,
  PeerInfo,
  NetworkMessage,
  SendResult,
  BroadcastOptions,
  MessageHandler,
  PeerSelector,
  NetworkEventType,
  NetworkEventHandler,
  NodeId
} from './types';

/** Rejestr wirtualnych węzłów (shared state dla testów) */
export const MockNetworkRegistry = new Map<NodeId, MockNetworkAdapter>();

export class MockNetworkAdapter implements NetworkAdapter {
  readonly nodeId: NodeId;
  readonly peers: PeerInfo[] = [];
  isReady = false;

  private config!: NetworkConfig;
  private messageHandlers: Map<string, Set<MessageHandler>> = new Map();
  private eventHandlers: Map<NetworkEventType, Set<NetworkEventHandler>> = new Map();
  private pendingSends: Map<string, NetworkMessage> = new Map();
  private messageLog: NetworkMessage[] = [];

  constructor(nodeId: NodeId) {
    this.nodeId = nodeId;
    MockNetworkRegistry.set(nodeId, this);
  }

  async init(config: NetworkConfig): Promise<void> {
    this.config = config;
    this.isReady = true;
    this.emit('network:ready', { nodeId: this.nodeId });
  }

  async shutdown(): Promise<void> {
    this.isReady = false;
    for (const peer of this.peers) {
      this.disconnect(peer.nodeId);
    }
    MockNetworkRegistry.delete(this.nodeId);
  }

  async connect(peer: PeerInfo): Promise<void> {
    if (this.peers.some(p => p.nodeId === peer.nodeId)) return;
    if (this.peers.length >= this.config.maxPeers) {
      throw new Error('Max peers reached');
    }
    
    this.peers.push({ ...peer, lastSeen: new Date() });
    this.emit('peer:connected', {}, peer);
  }

  disconnect(nodeId: NodeId): void {
    const idx = this.peers.findIndex(p => p.nodeId === nodeId);
    if (idx !== -1) {
      const peer = this.peers.splice(idx, 1)[0];
      this.emit('peer:disconnected', {}, peer);
    }
  }

  async send(target: NodeId, message: NetworkMessage): Promise<SendResult> {
    if (!this.isReady) return { success: false, delivered: false, error: 'Adapter not ready' };
    if (message.hopCount >= message.maxHops) return { success: false, delivered: false, error: 'TTL exceeded' };

    const targetAdapter = MockNetworkRegistry.get(target);
    if (!targetAdapter) return { success: false, delivered: false, error: 'Target not found' };

    const start = Date.now();
    const deliveredMessage = { ...message, hopCount: message.hopCount + 1, from: this.nodeId };
    
    // Symulacja opóźnienia sieciowego (1-10ms)
    await new Promise(res => setTimeout(res, Math.random() * 9 + 1));
    
    // Deliver
    targetAdapter.receiveMessage(deliveredMessage);
    this.messageLog.push(deliveredMessage);
    
    return {
      success: true,
      delivered: true,
      latency: Date.now() - start
    };
  }

  async broadcast(message: NetworkMessage, options?: BroadcastOptions): Promise<SendResult[]> {
    if (!this.isReady) return [];
    
    const results: SendResult[] = [];
    const ttl = options?.ttl ?? message.ttl;
    const maxHops = options?.maxHops ?? message.maxHops;
    const filter = options?.filterPeers ?? (() => true);

    for (const peer of this.peers) {
      if (!filter(peer)) continue;
      const broadcastMsg = { ...message, ttl, maxHops };
      results.push(await this.send(peer.nodeId, broadcastMsg));
    }
    
    return results;
  }

  subscribe(type: string, handler: MessageHandler): () => void {
    if (!this.messageHandlers.has(type)) {
      this.messageHandlers.set(type, new Set());
    }
    this.messageHandlers.get(type)!.add(handler);
    
    return () => {
      this.messageHandlers.get(type)?.delete(handler);
    };
  }

  async publish(type: string, payload: Record<string, any>): Promise<void> {
    const message: NetworkMessage = {
      id: crypto.randomUUID(),
      from: this.nodeId,
      type: type as any,
      payload,
      timestamp: Date.now(),
      ttl: 30000,
      hopCount: 0,
      maxHops: 10
    };
    await this.receiveMessage(message);
  }

  async findPeers(selector: PeerSelector): Promise<PeerInfo[]> {
    let results = [...this.peers];
    
    if (selector.capabilities?.length) {
      results = results.filter(p => 
        selector.capabilities!.every(cap => p.capabilities.includes(cap))
      );
    }
    if (selector.minTrust !== undefined) {
      results = results.filter(p => (p.trustScore ?? 0) >= selector.minTrust!);
    }
    
    return results.slice(0, selector.maxPeers ?? results.length);
  }

  on(event: NetworkEventType, handler: NetworkEventHandler): () => void {
    if (!this.eventHandlers.has(event)) {
      this.eventHandlers.set(event, new Set());
    }
    this.eventHandlers.get(event)!.add(handler);
    
    return () => this.eventHandlers.get(event)?.delete(handler);
  }

  // Internal
  private async receiveMessage(message: NetworkMessage): Promise<void> {
    if (Date.now() - message.timestamp > message.ttl) return;
    
    const handlers = this.messageHandlers.get(message.type) || new Set();
    for (const handler of handlers) {
      try {
        await handler(message);
      } catch (err) {
        console.error(`[MockNetwork] Handler error for ${message.type}:`, err);
      }
    }
    this.emit('message:received', message);
  }

  private emit(event: NetworkEventType,  any, peer?: PeerInfo): void {
    const handlers = this.eventHandlers.get(event) || new Set();
    for (const handler of handlers) {
      try { handler(data, peer); } catch (err) { console.error(err); }
    }
  }

  // Test helpers
  getMessageLog(): NetworkMessage[] {
    return [...this.messageLog];
  }
  
  clearMessageLog(): void {
    this.messageLog = [];
  }
}

/**
 * Serializacja i walidacja wiadomości sieciowych
 * @module network/message
 */

import { NetworkMessage } from './types';

/**
 * Kanoniczna serializacja JSON do podpisu / przesyłu
 */
export function serializeMessage(msg: NetworkMessage): Uint8Array {
  const sorted = Object.keys(msg).sort().reduce((acc, key) => {
    // Exclude undefined/optional fields from canonical form
    if (msg[key as keyof NetworkMessage] !== undefined) {
      acc[key] = msg[key as keyof NetworkMessage];
    }
    return acc;
  }, {} as Record<string, any>);
  
  return new TextEncoder().encode(JSON.stringify(sorted));
}

/**
 * Deserializacja z zachowaniem typów
 */
export function deserializeMessage( Uint8Array): NetworkMessage {
  const json = new TextDecoder().decode(data);
  return JSON.parse(json);
}

/**
 * Sprawdza czy wiadomość jest ważna (TTL, hops, struktura)
 */
export function isMessageValid(msg: NetworkMessage, maxAgeMs: number = 60000): boolean {
  const age = Date.now() - msg.timestamp;
  return age <= msg.ttl && age <= maxAgeMs && msg.hopCount < msg.maxHops;
}

/**
 * Inkrementuje hop count i zmniejsza TTL
 */
export function forwardMessage(msg: NetworkMessage): NetworkMessage {
  return {
    ...msg,
    hopCount: msg.hopCount + 1,
    ttl: Math.max(0, msg.ttl - 100) // -100ms per hop
  };
}

/**
 * Generuje wiadomość z domyślnymi polami
 */
export function createMessage(
  from: string,
  type: NetworkMessage['type'],
  payload: Record<string, any>,
  options?: Partial<Pick<NetworkMessage, 'to' | 'ttl' | 'maxHops' | 'signature' | 'nonce'>>
): NetworkMessage {
  return {
    id: crypto.randomUUID(),
    from,
    type,
    payload,
    timestamp: Date.now(),
    ttl: options?.ttl ?? 30000,
    hopCount: 0,
    maxHops: options?.maxHops ?? 10,
    to: options?.to,
    signature: options?.signature,
    nonce: options?.nonce ?? crypto.randomUUID()
  };
}

    const msg = createMessage('node-A', 'test/expire', { old: true }, { to: 'node-B', ttl: 50 });
    msg.timestamp = Date.now() - 100; // Expired
    
    expect(isMessageValid(msg)).toBe(false);
    
    // Mock adapter should drop it
    await nodeA.connect({ nodeId: 'node-B', address: '/b', publicKey: '0xb', capabilities: [], lastSeen: new Date() });
    const result = await nodeA.send('node-B', msg);
    expect(result.success).toBe(false);
    expect(result.error).toContain('TTL');
  });

  it('should find peers by capabilities', async () => {
    await nodeA.connect({ nodeId: 'node-B', address: '/b', publicKey: '0xb', capabilities: ['compute', 'storage'], lastSeen: new Date() });
    await nodeA.connect({ nodeId: 'node-C', address: '/c', publicKey: '0xc', capabilities: ['compute'], lastSeen: new Date() });
    
    const computePeers = await nodeA.findPeers({ capabilities: ['compute'] });
    expect(computePeers).toHaveLength(2);
    
    const storagePeers = await nodeA.findPeers({ capabilities: ['storage'] });
    expect(storagePeers).toHaveLength(1);

## 2.6 🔗 Przykład Integracji: Trust + Network

```typescript
// examples/network-trust-integration.ts
import { MockNetworkAdapter } from '../src/network/MockNetworkAdapter';
import { Identity } from '../src/trust/Identity';
import { TrustManager, TrustConfig } from '../src/trust/TrustManager';
import { createMessage } from '../src/network/message';

const trustConfig: TrustConfig = {
  defaultTrust: 0.2,
  trustDecayPerDay: 0.01,
  minTrustToInvite: 0.4,
  maxTrustLinks: 10,
  trustThresholdForCommunication: 0.3
};

async function runIntegration() {
  console.log('🌐 Initializing Trust + Network integration...\n');

  // 1. Tożsamości
  const alice = await Identity.generate();
  const bob = await Identity.generate();

  // 2. Network adapters
  const aliceNet = new MockNetworkAdapter(alice.nodeId);
  const bobNet = new MockNetworkAdapter(bob.nodeId);
  
  await aliceNet.init({ nodeId: alice.nodeId, maxPeers: 10, connectionTimeoutMs: 2000, messageBufferSize: 50, enableNatTraversal: false });
  await bobNet.init({ nodeId: bob.nodeId, maxPeers: 10, connectionTimeoutMs: 2000, messageBufferSize: 50, enableNatTraversal: false });

  // 3. Trust managers
  const aliceTrust = new TrustManager(alice, trustConfig);
  const bobTrust = new TrustManager(bob, trustConfig);

  // 4. Połącz węzły
  await aliceNet.connect({
    nodeId: bob.nodeId,
    address: '/ip4/127.0.0.1/tcp/4002',
    publicKey: bob.toPublicJSON().publicKey,
    capabilities: ['compute'],
    trustScore: 0.5,
    lastSeen: new Date()
  });

  // 5. Subskrypcja z weryfikacją trustu
  bobNet.subscribe('task/delegate', async (msg) => {
    const isTrusted = bobTrust.isTrusted(msg.from);
    console.log(`📥 Bob received task from ${msg.from.slice(0,8)}... | Trusted: ${isTrusted}`);
    if (isTrusted) {
      bobTrust.updateTrust(msg.from, 0.02, 'task_success');
    }
  });

  // 6. Alice wysyła zadanie
  console.log('📤 Alice delegating task...');
  await aliceNet.send(
    bob.nodeId,
    createMessage(alice.nodeId, 'task/delegate', { subject: 'P2P Routing', difficulty: 3 })
  );

  // 7. Sprawdź reputację po interakcji
  console.log('📊 Bob reputation after task:', bobTrust.getAuditLog().slice(-1)[0]);
  
  // Cleanup
  await aliceNet.shutdown();
  await bobNet.shutdown();
  console.log('\n✅ Integration test passed');
}

runIntegration().catch(console.error);
```

# Network Layer — Dokumentacja

## Przegląd
Warstwa sieciowa abstrahuje transport P2P, umożliwiając wymianę wiadomości, discovery peerów i pub/sub. Dostarcza `MockNetworkAdapter` do testów oraz interfejs `NetworkAdapter` do przyszłej integracji z `libp2p`.

| NAT Traversal | Pominęte | libp2p relay / hole punching |
| Testowalność | ✅ Deterministyczna | ❌ Wymaga izolacji sieci |
